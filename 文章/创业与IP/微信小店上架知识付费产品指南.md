# 微信小店上架知识付费产品指南

## 1. 开通微信小店

- **入口**：微信公众平台 → 「微信小店」，或直接访问 channels.weixin.qq.com
- **主体类型**：个人（有限制）/ 个体工商户 / 企业
- **建议**：用个体工商户或企业主体开通，品类权限更全

## 2. 选择商品类型

知识付费产品通常归类为：

| 类型 | 适用场景 | 说明 |
|------|---------|------|
| **虚拟商品** | 电子书、资料包、模板 | 需开通虚拟商品类目 |
| **在线课程** | 视频课、音频课 | 可结合视频号直播 |
| **付费专栏** | 系列内容、会员订阅 | 通过小程序承载 |

## 3. 类目选择与资质

- 进入「店铺管理」→「类目管理」→ 申请开通相关类目
- 虚拟商品/教育培训类目可能需要：
  - 营业执照（经营范围含教育咨询/信息技术等）
  - 相关资质证明（视具体类目要求）

## 4. 上架商品的步骤

```
商品管理 → 新增商品 → 填写信息 → 提交审核 → 上架
```

关键填写项：

- **商品标题**：突出核心价值，如「Python 入门到实战 · 30天系统课」
- **商品图片**：主图清晰有吸引力，建议 3:4 比例
- **详情描述**：课程大纲、学习收获、适合人群、交付方式
- **价格设置**：支持原价/划线价对比
- **交付说明**：明确写清楚如何交付（网盘链接/小程序/社群等）

## 5. 交付方案（核心问题）

微信小店本身不托管课程内容，需要选择交付方式：

### 方案 A：简单直接

- 用户下单后，通过**订单消息/客服消息**发送网盘链接或兑换码
- 适合：电子书、资料包、模板等一次性交付产品

### 方案 B：搭配小程序

- 开发或使用第三方知识付费小程序（如小鹅通、知识星球、有赞等）
- 微信小店负责成交，小程序负责内容交付
- 适合：系列课程、会员体系

### 方案 C：社群交付

- 下单后引导进入付费微信群/企业微信群
- 适合：训练营、陪跑服务、咨询类产品

## 6. 推广与流量

```
视频号短视频 → 挂商品链接
视频号直播   → 直播间上架
公众号文章   → 插入商品卡片
朋友圈/社群  → 分享商品链接
```

**视频号 + 微信小店** 是目前最核心的组合打法。

## 7. 注意事项

- **虚拟商品退款**：提前在商品详情里写清「虚拟商品，一经兑换不支持退款」
- **审核规范**：避免夸大宣传（如「月入十万」「保证就业」）
- **发货设置**：虚拟商品选择「无需物流」，设置自动确认收货
- **客服响应**：开通客服功能，及时回复用户咨询，影响店铺评分
