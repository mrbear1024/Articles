# 钓组与线组——把装备连成系统

单个装备再好，组装不对等于白搭。本模块教你从零搭建一套完整的钓组。

---

## 2.1 台钓线组的标准结构

台钓线组是一个从竿稍到鱼钩的完整传动系统。每一个配件都有特定的位置和功能，遗漏或顺序颠倒都会影响钓组的正常工作。

**从竿稍到鱼钩的完整连接顺序**

```
竿稍绳 → 主线 → 太空豆×2 → 漂座 → 太空豆×1 → 太空豆×2 → 铅皮座 → 太空豆×1 → 八字环 → 子线×2（双钩）
```

**每个配件的功能与安装位置**

- **竿稍绳**：连接竿稍蛇口和主线的过渡绳。通常竿子出厂自带，损坏后可单独更换。
- **主线上端太空豆（2 颗）**：固定漂座上端位置。两颗而非一颗是为了防止单颗滑动。
- **漂座**：插入浮漂的支架，被上下两组太空豆夹持固定。通过移动太空豆的位置来调整浮漂在主线上的高度，进而调整钓水深度。
- **漂座下方太空豆（1 颗）**：固定漂座下端位置。
- **铅皮座上方太空豆（2 颗）**：限制铅皮座上移。
- **铅皮座**：卷铅皮的支架。铅皮提供配重，让浮漂在水中达到平衡状态。
- **铅皮座下方太空豆（1 颗）**：限制铅皮座下移。
- **八字环（转环）**：连接主线和子线的枢纽。主线在上方打结固定，子线在下方通过活扣连接。八字环可以自由旋转，防止子线因鱼的挣扎而绞缠主线。
- **子线（双钩）**：从八字环分出两根子线，各绑一枚鱼钩。两钩之间保持一定距离（钩距），通常为 1.5–2 个钩距。

**主线线组制作全流程**

1. 量线：将主线拉出，长度等于鱼竿长度加上 20–30cm 的余量
2. 在主线顶端打一个双扣结（用于连接竿稍绳）
3. 从下往上依次穿入配件：太空豆→漂座→太空豆→太空豆→铅皮座→太空豆
4. 在主线末端绑上八字环
5. 剪去多余线头
6. 调整各太空豆的间距，漂座到铅皮座的距离大约等于你预期的钓水深度

**子线绑制与双钩距离**

子线长度通常在 15–25cm（对折后的单边长度）。两钩之间的距离（钩距）影响鱼的吸食效率：

- 钓小鲫鱼：钩距 1.5–2cm（约 1.5 个钩长）
- 钓大鲫鱼：钩距 2–3cm
- 钓鲤鱼等大型鱼：钩距 3–5cm

子线绑好后，对折找到中点，在中点处打一个"8"字结，形成一个小线圈，用于挂在八字环上。

## 2.2 常用结节与绑法

结节是线组中最薄弱的环节。打结方式直接决定线组的实际强度——好的结节可以保留原始拉力的 85% 以上，差的结节可能只剩 50%。

**竿稍绳结（蛇口结）**

将主线连接到竿稍绳上的方法：

1. 在主线顶端打一个双扣活结（拉一头可以收紧的环结）
2. 将竿稍绳穿过主线的活结圈
3. 收紧主线，让活结锁死在竿稍绳上
4. 收竿时拉松活结即可快速解开

这种连接方式的优点是安装和拆卸都很快，且不会损伤竿稍绳。

**八字环连接结**

将主线固定到八字环上：

1. 将主线穿过八字环的上环
2. 绕回来再穿一次，形成一个双圈
3. 主线末端在主线本体上缠绕 4–5 圈
4. 将末端穿回双圈中
5. 沾水后缓慢收紧（沾水能减少摩擦热对尼龙线的伤害）

**子线绑钩结（内走线绑法）**

这是最通用的绑钩方法，详细步骤已在模块 1.3 中说明。核心要点重复一遍：

- 缠绕圈数 7–8 圈，少于 5 圈容易滑脱
- 拉紧前必须沾水
- 绑好后确认钩尖与子线在同一方向（钩尖朝外），否则需要重绑

**各类结节的强度对比**

| 结节类型 | 拉力保留率 | 适用场景 |
|---------|-----------|---------|
| 内走线绑钩结 | 85–90% | 绑钩（最推荐） |
| 双扣活结 | 75–80% | 连接竿稍绳 |
| 八字环连接结 | 80–85% | 主线连八字环 |
| 简单单结 | 50–60% | 不推荐用于钓组 |

## 2.3 海竿 / 抛竿线组基础

海竿（抛竿）线组与手竿线组的根本区别在于：海竿通过卷线器放线和收线，钓组可以抛到几十甚至上百米外。

**纺车轮的装线与调节**

纺车轮是新手最容易上手的卷线器类型。装线前需要了解三个关键部件：

- **线杯**：储存鱼线的筒。装线量以线杯边缘留 1–2mm 空间为标准，装太满会频繁炸线，装太少影响抛投距离。
- **曳力**（泄力）：通过旋钮调节出线阻力。当鱼的拉力超过设定值时，线杯自动放线，避免断线。设定值通常为子线拉力的 1/3 到 1/2。
- **逆止开关**：控制手柄是否可以反转。正常作钓时关闭逆止（手柄不能反转），需要手动放线时打开。

装线步骤：

1. 打开纺车轮的线挡臂（半圆形金属臂）
2. 将鱼线从竿稍方向穿过每一个导环
3. 将线头绑在线杯上（绕一圈打死结）
4. 关闭线挡臂
5. 一手捏住主线施加适度张力，一手匀速摇轮收线
6. 装满至距离线杯边缘 1–2mm 处即可

**串钩钓组**

串钩是海竿最基础的钓组。结构简单，从上到下排列多枚鱼钩（通常 3–5 枚），底部挂铅坠。

- 优点：多钩同时作钓，可以搜索不同水层
- 适用场景：水库守钓鲫鱼、鲤鱼，海边沙滩钓
- 挂饵：蚯蚓、红虫、玉米粒等

**爆炸钩钓组**

爆炸钩是专门为远投守大鱼设计的钓组。多枚鱼钩围绕一团饵料球，鱼来啃食饵料时将钩子一并吸入。

- 结构：6–8 枚鱼钩呈放射状排列，中间有弹簧托饵器
- 饵料：用粘性较强的商品饵或自制饵料捏成拳头大小的球
- 适用场景：水库、湖泊守钓大鲤鱼、大草鱼

**浮钓钓组**

当目标鱼在水的中上层活动时（如鲢鳙、翘嘴），需要用浮钓钓组。

- 在主线上增加一个大号浮球或阿波漂，让钓组悬浮在指定水层
- 通过调整浮球到鱼钩的距离来控制钓棚深度

**铅坠形状与水流的关系**

- **圆形铅坠**：容易被水流推动，适合静水
- **扁形铅坠**：贴底稳定，适合有流速的河流
- **条形铅坠（通心坠）**：穿在主线上可以自由滑动，适合做滑铅钓组

## 2.4 路亚钓组入门

路亚钓法使用拟饵（假饵）模拟小鱼、虾、虫等猎物的动作来引诱掠食性鱼类攻击。钓组的设计目的是让拟饵呈现最自然的泳姿。

**纺车轮与水滴轮的区别与选择**

| 对比项 | 纺车轮 | 水滴轮 |
|--------|--------|--------|
| 上手难度 | 容易 | 较难（容易炸线） |
| 抛投精准度 | 一般 | 高 |
| 适合饵重 | 3g 以上 | 7g 以上 |
| 适合线种 | PE 线、尼龙线 | PE 线、尼龙线 |
| 推荐人群 | 新手入门首选 | 有一定基础后升级 |

**三种基础路亚钓组**

1. **德州钓组（Texas Rig）**
   - 结构：子弹型铅 + 挡珠 + 曲柄钩 + 软饵
   - 特点：防挂底能力强，适合在障碍物区域（水草、石堆）使用
   - 操控：抛到标点后沉底，通过轻抽竿稍让软饵在底部跳跃前进

2. **倒吊钓组（Drop Shot）**
   - 结构：鱼钩绑在子线中间（侧绑），铅坠挂在子线末端
   - 特点：饵在铅坠上方悬浮，可以在一个点反复抖动引诱
   - 操控：铅坠触底后，轻轻抖动竿稍让软饵原地摇摆

3. **无铅钓组（No Sinker Rig）**
   - 结构：曲柄钩 + 软饵，不加任何配重
   - 特点：软饵自然下沉，泳姿最真实
   - 操控：适合浅水区和鱼活性高的时候使用

**前导线的作用与连接方式**

路亚钓法中，PE 线（编织线）通常作为主线，但 PE 线有两个明显缺点：不耐磨、水中可见度高。因此需要在 PE 线末端连接一段碳氟前导线（Leader），长度通常 1–1.5m。

前导线的连接方式：

- **FG 结**：强度最高（可保留 95% 以上拉力），是路亚钓手最推荐的 PE 线与前导线连接方式。编织步骤较复杂，需要反复练习。
- **摩擦结（GT 结）**：操作比 FG 结简单，强度略低。新手可以先用 GT 结过渡，后续学会 FG 结再替换。

前导线号数的选择：与 PE 线的拉力值匹配即可，通常碳氟线比 PE 线粗 2–3 号。
