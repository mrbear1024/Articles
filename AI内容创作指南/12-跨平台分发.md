# 模块 12：一次生产、多平台分发

> 内容创作中最浪费的事：为每个平台从零创作。
> 最聪明的做法：一次深度生产 → AI 帮你"变形"到 N 个平台。
> 你的思考只需要做一次，但触达要做 N 次。

---

## 12.1 核心理念：内容不是"一对一"，而是"一对多"

### 内容形态转换矩阵

| 原始内容 | 可转化为 |
|----------|---------|
| YouTube 长视频 (10min) | 5 条短视频 + 3 条 X Thread + 1 篇 Newsletter + 1 篇博客 |
| 长文 Newsletter | 1 个 3 分钟视频脚本 + 1 条 Reel + 10 条 X + 5 条小红书 |
| X Thread (10 条) | 1 篇 Newsletter + 1 个 90 秒视频 + 3 条小红书 |
| 播客 (30min) | 5 条短视频 + 文字稿 Newsletter + 10 条金句推文 |
| 一次演讲 | 完整录像 + 10 条精华片段 + 文字稿 + Thread + Newsletter |

### 一鱼多吃的原则

1. **从最深的形态开始**：先做最深度的内容（长文或长视频），再往外拆。
2. **不是简单截取——是重新包装**：每个平台需要不同的开头、节奏、CTA。
3. **AI 最擅长的就是"同一内容，换形态"**——这是它的甜点区间。

---

## 12.2 各平台的语感差异

### 平台 DNA 速查

| 平台 | 语气 | 句长 | 情绪 | 禁忌 |
|------|------|------|------|------|
| **X (Twitter)** | 犀利、直接、有态度 | 极短（10-20字/句） | 挑衅/洞察 | 长篇大论 |
| **Substack** | 深度、个人、对话感 | 中等 | 思考/真诚 | 标题党 |
| **小红书** | 亲切、实用、生活感 | 短-中 | 温暖/有用 | 说教/冷冰冰 |
| **B 站** | 社区感、懂梗 | 中等 | 热情/调侃 | 端着/不接地气 |
| **抖音/TikTok** | 快、直接、情绪化 | 极短 | 冲击/好奇 | 慢热 |
| **YouTube** | 专业、有深度 | 中-长 | 价值感 | 注水 |
| **LinkedIn** | 职业、故事、反思 | 中等 | 启发/成长 | 过度推销 |

### AI 跨平台改写提示词

```
以下是我的原始内容（一篇 Newsletter / 一个视频脚本）：

[粘贴原始内容]

请改写为以下平台版本：

1. X Thread（7-10 条，每条独立可读，有钩子+CTA）
2. 小红书文案（300字以内，亲切口语化，分段+emoji 适度使用）
3. 抖音/TikTok 脚本（60秒，HPAR 结构，口播风格）
4. LinkedIn 帖子（200字，职业语气，以个人故事开头）

每个版本请：
- 适配该平台的语气和句长
- 重写开头（不同平台需要不同的钩子）
- 调整 CTA（不同平台的用户习惯不同）
- 保持核心观点一致
```

## 12.3 长视频 → 短视频 的拆解

### 自动化工具

| 工具 | 功能 | 输出 |
|------|------|------|
| **Opus Clip** | AI 识别"高光时刻"自动裁剪 | 多条 60 秒以内短视频 |
| **Vizard** | AI 识别 + 字幕 + 竖屏裁剪 | 适配各平台的短视频 |
| **CapCut 智能成片** | 一键从长视频截取精华 | 快速变体 |
| **Descript** | 在文稿中标记片段 → 导出 | 精确控制的裁剪 |

### 手动策略（质量更高）

1. **看完整视频，标记 5-8 个"独立可看"的片段**
   - 每个片段要有自己的起承转合
   - 不需要前文铺垫就能理解

2. **为每个片段重新写开头钩子**
   - 原视频的第 5 分钟不能直接做短视频开头
   - 需要一个新的 3 秒钩子

3. **竖屏适配**
   - 横屏 16:9 → 竖屏 9:16：裁剪焦点在人物/文字
   - 或者：横屏画面放中间，上下加文字/字幕

4. **每条短视频配独立的标题和封面**

## 12.4 文字 → 视频 的转化

### Newsletter/文章 → 视频脚本

```
提示词：

请将以下文章转化为一个 [X] 分钟的 [平台] 视频脚本：

[粘贴文章]

要求：
1. 使用 HPAR 结构
2. 口播语气（像朋友聊天，不是念稿）
3. 为每段口播建议"画面描述"
4. 删掉所有只适合阅读不适合听的内容
5. 句子控制在 20 字以内
6. 每 30 秒一次 micro-hook
```

### 关键转化点

- **文章中的数据** → 视频中的数据可视化（图表动画）
- **文章中的引用** → 视频中的文字弹出 + 口播
- **文章中的长论证** → 视频中压缩为一个比喻或故事
- **文章中的列表** → 视频中逐条弹出（每条 5-10 秒）

---

## 12.5 视频 → 文字 的转化

### 视频脚本/录音 → Newsletter

```
提示词：

以下是我的视频脚本/转录文字：

[粘贴]

请将其改写为一期 Newsletter，要求：
1. 不要像"视频文字版"——要像一封独立的信
2. 加入适合阅读（而非听觉）的内容：数据表格、链接、引用出处
3. Cold Open 重写（阅读的钩子不同于视频的钩子）
4. 加入 Takeaway 清单（视频不一定有但 Newsletter 需要）
5. 结尾加 Newsletter 专属 CTA
```

## 12.6 分发节奏与排期

### 推荐周节奏（个人创作者）

```
周一：发布 Newsletter（核心内容）
周二：Newsletter 精华 → X Thread + 小红书
周三：X 短推文（延续话题讨论）
周四：录制/剪辑本周视频
周五：发布视频（YouTube/B站）
周六：视频 → 3 条短视频分发
周日：选题 + 下周 Newsletter 研究

循环。
```

### 自动化与批量处理

- **批量生产日**：每月用 1-2 天集中录制 4-8 个视频（一天录完一个月的量）
- **AI 批量改写**：一篇核心内容写完后，用 AI 一次性生成所有平台的变体
- **排期工具**：Buffer / Hootsuite / X Pro / 小红书创作者工具

---

## 12.7 跨平台增长飞轮

```
[深度内容] (Newsletter/YouTube)
     ↓
[短内容分发] (X/小红书/TikTok/Shorts)
     ↓
[新粉丝发现你]
     ↓
[引导到"根"](订阅 Newsletter / YouTube 频道)
     ↓
[深度内容继续服务]
     ↓
[粉丝分享 → 新的短内容传播]
     ↓
循环加速
```

**关键**：每个短内容都要有一条"回到深度内容"的路径。没有回流机制 = 只在做"流量"，没在做"资产"。

---

## 12.8 实践任务

1. **一鱼多吃**：拿你上周的一篇 Newsletter（或一条 Thread），用 AI 转化为另外 3 个平台的内容，并发布。
2. **长拆短**：如果你有长视频，用 Opus Clip 自动拆出 3 条短视频——看 AI 选的片段和你心目中的是否一致。
3. **建立模板**：在你的 AI 工具中保存一个"跨平台改写 System Prompt"，以后一键调用。
4. **排期计划**：写出你的"周节奏表"——什么时候生产、什么时候分发、什么时候互动。
