# 模块 2：AI 写作工作流（Human-in-the-Loop）

> 核心理念：AI 是你的副驾驶，不是司机。
> 你的观点、判断和个人经历是不可替代的；AI 帮你加速执行。

---

## 2.1 五步法：构思 → 研究 → 结构 → 初稿 → 改写

### Step 1：构思（Ideate）——用 AI 做"扩散"

**目的**：从一个模糊的种子想法，扩散出 20+ 个可能的角度。

**做法：**
- 把你脑中的"一句话想法"给 AI，要求它从不同维度展开。
- 关键：**不要只要一个答案——要一堆选项**。

**提示词模板：**

```
我有一个选题方向：[你的想法]。
请从以下 6 个维度各给我 3 个具体角度：
1. 反常识/对立观点
2. 个人故事/经历切入
3. 数据/研究驱动
4. 类比/跨领域联想
5. 时事/热点挂钩
6. 实操/方法论

每个角度用一句话概括，附上一条"为什么读者会点开"的理由。
```

**人的工作：** 从 18 个角度中挑 1-3 个最让你兴奋的。兴奋 = 你有话想说。

---

### Step 2：研究（Research）——用 AI+搜索做"收敛"

**目的**：为选定的角度收集事实、数据、案例、对立观点。

**做法：**
- 用 Perplexity / ChatGPT Search / Kimi 做初步搜索。
- 用"反向提问"让 AI 找你的盲点。

**反向提问模板：**

```
我打算写的核心观点是：[你的论点]。
请扮演一个持反对意见的专家，从以下角度挑战我的观点：
1. 我的论据中最薄弱的是哪条？为什么？
2. 有没有权威的反面案例或数据？
3. 我可能忽略了哪个关键的前提条件？
4. 如果我的观点错了，最可能错在哪里？

不需要客气，越尖锐越好。
```

**人的工作：** 面对 AI 的挑战，决定是修正你的观点、增加限定条件、还是直接回应反驳。

---

### Step 3：结构（Outline）——人定骨架，AI 填肉

**目的**：建立文章的金字塔结构。

**做法：**
- **你来写核心论点（1 句话）和 3 个支撑点（每个 1 句话）。** 这 4 句话 AI 不能替你写。
- 让 AI 在你的框架下补充子论点、过渡句、可能的案例位置。

**提示词模板：**

```
我的文章结构如下：

核心论点：[一句话]
支撑点1：[一句话]
支撑点2：[一句话]
支撑点3：[一句话]

请：
1. 为每个支撑点建议 2 个子论点
2. 为每个子论点建议一个"最佳案例类型"（数据/故事/类比/引用）
3. 建议开头钩子的 3 种可能方式
4. 建议结尾收束的 2 种方式
```

**人的工作：** 审视结构是否反映你真正想说的话，而不只是"逻辑上通顺"。

---

### Step 4：初稿（Draft）——分段生成，不要一次出完

**目的**：生成可迭代的文字草稿。

**关键原则：**
- **不要说"请帮我写一篇 3000 字的文章"。** 这会得到一坨均质的泡沫。
- **按段生成**：一次给 AI 一段的任务。每段 200-400 字。
- **每段给上下文**：告诉它前面写了什么、后面要写什么、这段的功能是什么。

**单段生成模板：**

```
[上文已完成内容的最后一段]

现在请写：[这一段的内容要求]
功能：[引入论点 / 举例说明 / 过渡 / 总结]
字数：[200-400]
语气参考：[你的声音指南或参考文章链接]

注意：
- 开头不要重复上一段已经说过的话
- 用主动语态
- 至少包含一个具体的例子或数字
```

**人的工作：** 每段生成后立即读一遍——不满意直接要求重写，不要积累到最后再改。

---

### Step 5：改写（Rewrite）——AI 占比降到 30% 以下

**目的**：把"AI 写的文章"变成"你写的文章"。

**这一步最重要。** 如果你只做一步，做这一步。

**改写清单：**

1. **洗掉 AI 味**
   - 删除"此外"、"值得注意的是"、"总而言之"、"在当今"等 AI 高频套话。
   - 删除所有"首先...其次...最后"的机械排列——换成自然过渡。
   - 把"我们"改成"我"或"你"——自媒体要有第一人称的亲近感。

2. **注入你自己**
   - 每 500 字至少加一个"只有你知道"的细节（你的经历、你的观察、你的感受）。
   - 加入你的口头禅、你的比喻方式。

3. **节奏打磨**
   - 朗读一遍——嘴巴觉得别扭的地方，改。
   - 三个长句之后，插一个短句。"就这样。""不行。""但真相是——"

4. **事实核查**
   - AI 引用的数据和案例，逐条验证来源。
   - 如果找不到来源——删掉或替换。

**AI 辅助改写的用法：**

```
请帮我改写以下段落，要求：
1. 删除所有副词和修饰性套话
2. 把被动语态改成主动语态
3. 每超过 30 字的句子拆成两句
4. 保留原意，不加新内容

[粘贴段落]
```

## 2.2 反模式：不要这样用 AI 写作

### ❌ 反模式 1："请帮我写一篇关于 X 的文章"

**问题**：没有给 AI 任何约束 = 得到最"平均"的输出。
**替代**：给角度、给结构、给语气、给受众——约束越多，输出越好。

### ❌ 反模式 2：让 AI 替你做观点判断

**问题**："你觉得这个话题应该持什么立场？"——AI 的立场是统计学上最安全的中间值。
**替代**：你先有观点，让 AI 帮你强化论证或找反例。

### ❌ 反模式 3：一次生成 → 直接发布

**问题**：经验丰富的读者一眼就能看出未经改写的 AI 文——语气均匀、缺乏个人细节、结构工整但无记忆点。
**替代**：至少经过一轮"洗 AI 味"改写（见 Step 5）。

### ❌ 反模式 4：只用一个模型

**问题**：每个模型有自己的"语感指纹"。长期只用一个模型，你的内容会带上那个模型的味道。
**替代**：混用。Claude 写初稿 → GPT 改写 → DeepSeek 做中文润色 → 你自己最后过一遍。

### ❌ 反模式 5：把 AI 当"完美机器"

**问题**：AI 会编造数据、虚构引用、捏造"研究表明"。
**替代**：所有事实性陈述，必须人类验证。把 AI 当实习生——聪明但不可靠。

## 2.3 推荐模型组合

### 长文 / 深度推理

| 模型 | 优势 | 适合场景 |
|------|------|---------|
| Claude Opus/Sonnet | 长上下文、逻辑性强、中文质量好 | 万字长文、研究综述、复杂结构 |
| GPT-4o / o1 / o3 | 知识广度、创意强 | 初稿生成、头脑风暴 |
| Gemini Pro | 超长上下文、多模态 | 处理大量参考资料 |

### 中文内容 / 本地化

| 模型 | 优势 | 适合场景 |
|------|------|---------|
| DeepSeek | 中文语感佳、推理强 | 中文长文、技术内容 |
| Kimi | 超长文档处理 | 读研报、读论文后写总结 |
| 通义千问 | 阿里生态、中文自然 | 电商文案、日常内容 |
| 豆包 | 字节生态、社交内容感好 | 短视频脚本、社交文案 |

### 搜索式写作

| 工具 | 用途 |
|------|------|
| Perplexity | 带引用的实时搜索——做研究步骤的核心工具 |
| ChatGPT Search | GPT 集成搜索 |
| Kimi 搜索 | 中文搜索质量好 |

### 批量 / 定制

| 方案 | 用途 |
|------|------|
| 本地小模型 (Llama/Qwen via Ollama) | 不花钱的批量改写、格式转换 |
| API 调用 + Few-shot | 用你旧文做示例，定制输出风格 |
| Custom GPTs / Claude Projects | 预设角色和知识库 |

## 2.4 "AI 味"检测清单

改完稿后，用这个清单自检——如果超过 3 条命中，需要继续改写：

- [ ] 文中有"在当今...的背景下"或"随着...的快速发展"
- [ ] 开头使用了"引言"或"概述"类的元叙述
- [ ] 每段首句都是"首先/其次/此外/最后"
- [ ] 全文没有一个"我"字
- [ ] 全文没有一个具体的个人经历
- [ ] 所有句子长度几乎一样（没有节奏变化）
- [ ] 出现"综上所述""值得注意的是""不可否认"
- [ ] 结尾是"让我们一起期待..."或"相信在未来..."
- [ ] 所有例子都是"比如苹果公司""比如特斯拉"（AI 最爱举这几个例子）
- [ ] 文中引用了你无法核实来源的"研究表明"

## 2.5 实践任务

**今日挑战**：用五步法完成一条 X Thread（5-7 条），主题自选。

1. 构思：让 AI 给你 20 个角度，挑 1 个。
2. 研究：让 AI 找 3 个支撑数据 + 1 个反面观点。
3. 结构：自己写核心论点 + 3 个支撑点。
4. 初稿：让 AI 逐条生成 Thread。
5. 改写：用检测清单过一遍，洗掉 AI 味。

计时目标：**45 分钟以内完成**——这就是 AI 带来的效率。
