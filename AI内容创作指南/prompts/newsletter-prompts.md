# Newsletter 提示词模板库

---

## 1. 选题研究

```
我的 Newsletter 定位是：[一句话描述]
目标读者：[画像]
我的 3 个核心母题是：[列出]

请帮我做本周的选题分析：
1. 在 [领域] 中，本周有哪些值得讨论的新进展/事件？
2. 对每个事件，给出和我母题的关联度（1-5）
3. 推荐 3 个选题，说明：
   - 核心角度（一句话）
   - 为什么我的读者会关心
   - 与我之前内容的连接点
```

## 2. Cold Open 生成

```
本期 Newsletter 核心论点是：[一句话]
目标读者：[画像]

请用以下 3 种方式各写一个 Cold Open（50-150 字）：
1. 场景入手：描述一个具体的瞬间/场景
2. 金句入手：一句有冲击力的话（可以是名人引言或你的原创）
3. 问题入手：一个直击读者痛点的问题

要求：
- 第一句就让人想往下读
- 不要以"在当今..."或"随着..."开头
- 语气像给一个聪明的朋友写信
```

## 3. 主体内容生成

```
本期 Newsletter 的结构如下：

核心论点：[一句话]
支撑点1：[一句话]
支撑点2：[一句话]  
支撑点3：[一句话]

请为每个支撑点写 200-300 字的段落：
- 使用金字塔结构（每段第一句是小结）
- 证据类型：数据/引用/个人经历三选二
- 语气参考：[粘贴你的声音指南]
- 不要用"首先/其次/此外"做过渡
- 自然过渡到下一个支撑点
```

## 4. Takeaway 生成

```
以下是我这期 Newsletter 的主体内容：
[粘贴]

请提炼 3 条 Takeaway：
- 具体、可执行（不要"保持学习"——要"今天做 X 事"）
- 每条 1-2 句话
- 读者可以不看全文，只看 Takeaway 就有收获
```

## 5. 邮件标题生成

```
以下是我这期 Newsletter 的摘要：
[粘贴 100 字摘要]

请生成 10 个邮件标题（Subject Line）：
- 每个不超过 50 字符
- 分别使用以下模式各 2 个：
  1. 具体承诺
  2. 好奇心缺口
  3. 时效性
  4. 直接对话
  5. 数字+结果
- 不要感叹号
- 不要全大写
```

## 6. Newsletter 改写（洗 AI 味）

```
以下是 AI 生成的 Newsletter 初稿：
[粘贴]

请改写：
1. 删除所有"在当今""值得注意的是""总而言之"等套话
2. 把语气从"写给公众"改成"写给一个朋友"
3. 标记 [需要个人经历] 的位置——这些地方我需要手动补充
4. 每 500 字检查一次是否有"你"出现——如果没有，加入直接对读者说话的句子
5. 结尾写一个有个人温度的 Sign-off
```

## 7. 研究漏斗

```
我正在为下一期 Newsletter 做研究。主题是：[主题]

请帮我：
1. 总结这个话题下最重要的 5 个观点/进展
2. 找出最有争议的 2 个立场（正方+反方论据）
3. 列出 3 个"大多数人不知道"的冷知识或数据
4. 推荐 3 篇值得深读的文章/报告（给出搜索关键词）
5. 提出 2 个"可以成为独特角度"的切入点

每一项都给出关键细节和来源线索（我会自己去验证）。
```

## 8. 系列规划

```
我想做一个 [N] 期的 Newsletter 系列，主题是：[大主题]

请帮我规划：
1. 系列的整体叙事弧线（从什么开始，到什么结束）
2. 每期的子主题和核心论点（一句话）
3. 期与期之间的衔接点
4. 系列预告文案（150 字，用于第一期发布前的推广）

要求：
- 每期可以独立阅读，但连起来有递进
- 难度从浅到深
- 最后一期有总结性和行动号召
```
