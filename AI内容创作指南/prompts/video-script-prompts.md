# 视频脚本提示词模板库

---

## 1. 完整脚本生成

```
请为我写一个视频脚本：

平台：[YouTube / B站 / 抖音 / 小红书 / X]
时长：[X 分钟 / X 秒]
类型：[口播 / 旁白配画面 / 教程演示 / 故事型]
选题：[你的选题]
核心论点：[一句话]
目标受众：[画像——年龄、身份、痛点、认知水平]
结构模板：[HPAR / 问题-错误-正确 / 故事弧线 / 清单速递]

要求：
1. 两栏格式（左：时间+画面描述 / 右：口播文字）
2. 前 3 秒必须有让人停下来的钩子
3. 每 30 秒一次 micro-hook（新信息/语气变化/画面切换提示）
4. 口播像和朋友说话，不像念稿
5. 标注 [停顿] [加重] [画面切] 的位置
6. 句子不超过 25 字
7. 每 30 秒至少一次"你"
8. 结尾有具体 CTA
9. 不要使用"首先/其次/此外/值得注意的是"

语气参考：
[粘贴你的声音指南或一段你满意的旧脚本]
```

## 2. 3 秒钩子生成

```
我的视频选题是：[选题]
目标受众：[画像]
平台：[平台]

请生成 10 个"3 秒钩子"方案，每个包含：
1. 口播文字（不超过 20 字）
2. 画面描述（一句话）
3. 钩子类型（视觉冲突/信息承诺/情绪爆发/直接提问/反常识）

让我从中选最强的那一个。
```

## 3. 分镜 Prompt 清单

```
以下是我的视频脚本：
[粘贴脚本]

请为每个场景/段落生成：
1. 镜头类型（特写/中景/远景/俯视/动态跟随）
2. 画面核心元素
3. 建议素材来源（实拍/AI生成/屏幕录制/版权素材库）
4. 如果用 AI 生成，给出 Midjourney/Flux Prompt
5. 情绪/色调关键词

按时间顺序排列，格式清晰。
```

## 4. 脚本口播化改写

```
以下是一段书面风格的脚本：
[粘贴]

请改写为口播风格：
1. 句子不超过 20 字
2. 把被动语态改成主动语态
3. 把"人们""大家"改成"你"
4. 删除所有学术化/书面化表达
5. 加入口语过渡（"你想想看""关键来了""说实话"）
6. 在需要停顿的地方加 / 和 //
7. 长句后接短句
8. 朗读起来像和朋友聊天
```

## 5. 脚本压缩

```
以下脚本目前是 [X] 分钟，需要压缩到 [Y] 分钟：
[粘贴]

请压缩，要求：
1. 保留核心论点和最强的例子
2. 删掉重复表达和过渡废话
3. 合并可以合并的段落
4. 标注你删掉了什么（让我确认）
5. 压缩后仍然保持完整的叙事弧线
```

## 6. 跨平台脚本改写

```
以下是我的 [原平台] 视频脚本（[X] 分钟）：
[粘贴]

请改写为以下版本：

1. [抖音/TikTok] 60秒版
   - HPAR 结构
   - 保留最强的 1 个核心观点
   - 3 秒钩子重写

2. [YouTube Shorts] 45秒版
   - 信息密度高
   - 可循环（结尾连接开头）
   
3. [小红书] 90秒版
   - 亲切口语
   - 生活感切入
   - 适合竖屏

每个版本都是完整的两栏脚本。
```

## 7. 教程/演示脚本

```
我要做一个 [工具/技能] 的教程视频：

教什么：[具体技能]
面向谁：[初学者/中级/高级]
平台：[平台]
时长：[X 分钟]

请生成脚本，结构：
1. 钩子：展示最终效果（"看完这个视频你能做到 X"）
2. 为什么你需要这个（痛点）
3. Step-by-step 教学
   - 每步：口播说明 + 屏幕画面描述
   - 每步结束确认（"做到这一步了吗？"）
4. 常见错误 + 避坑
5. 总结 + CTA

标注所有需要 [屏幕录制] 的位置。
```

## 8. 选题到脚本一条龙

```
我的领域是：[领域]
我的受众是：[画像]
我的母题是：[3 个母题]
今天想做一个 [平台] 的 [X 分钟] 视频。

请帮我：
1. 推荐 3 个选题（附理由）
2. 我选定后，你再生成完整的两栏脚本

先给选题，等我选。
```
