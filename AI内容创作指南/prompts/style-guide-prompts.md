# 声音/风格指南提取提示词

---

## 1. 声音提取（从旧作中分析你的写作风格）

```
以下是我过去写的 [N] 篇最满意的内容。请分析我的写作声音，输出一份《作者声音指南》：

1. 高频词（出现 3 次以上的关键词，列 10 个）
2. 避讳词（我从未使用的常见表达，列 10 个）
3. 句式偏好：
   - 平均句长（字数）
   - 长短句比例
   - 设问句使用频率
   - 主动/被动语态比例
   - 是否爱用排比/类比
4. 比喻与意象来源（比喻素材来自哪些领域？科技/自然/体育/日常生活/...）
5. 开头的固定手法（归纳 2-3 种常见的开头模式）
6. 结尾的固定手法（归纳 2-3 种常见的结尾模式）
7. 情感基调（用 3 个形容词概括整体调性）
8. 世界观倾向（用 1-2 句话概括——乐观/务实/怀疑/理想主义/...）
9. 禁忌：这个作者绝不会用的表达方式或句式

输出格式：可以直接复制粘贴到 AI 工具的 System Prompt 中使用的"声音指南"。

---

我的内容：
[粘贴 10-20 篇内容]
```

## 2. 声音指南转化为 System Prompt

```
以下是我的声音指南分析结果：
[粘贴上一步的输出]

请将其转化为一个可直接使用的 System Prompt，格式如下：

---
你是 [我的名字] 的写作助手。以下是 [我的名字] 的写作声音指南，所有输出都必须遵循：

[声音特征]
[句式要求]
[禁止事项]
[语气示例——给出 2-3 个好的句子作为参考]
---

Prompt 要简洁（不超过 300 字），便于复制粘贴到任何 AI 工具中。
```

## 3. 声音一致性检查

```
以下是我的声音指南：
[粘贴声音指南]

以下是我刚写（或 AI 帮我写）的一段内容：
[粘贴内容]

请检查这段内容与我的声音指南的一致性：
1. 哪些部分符合我的声音？（具体指出）
2. 哪些部分不像我？（具体指出并说明原因）
3. 给出修改建议——让不像我的部分"听起来像我"
4. 用我的声音重写不一致的段落
```

## 4. 母题提取

```
以下是我过去 [N] 篇内容。请分析我的内容母题：

1. 哪些话题/概念在不同文章中反复出现？（列出 5-10 个高频主题）
2. 我似乎反复在探讨哪 3-5 个"元问题"？
   - 用"[作者] 一直在追问的问题是：____"的格式
3. 我的内容中隐含的"信念"或"价值判断"是什么？
   - 关于 [领域]，我相信什么？
   - 我认为什么是重要的？什么是不重要的？
4. 建议我将母题收敛为 3 个核心主题词

我的内容：
[粘贴]
```

## 5. 目标声音靠近（学习某个作者的风格）

```
以下是 [目标作者] 的 5 篇代表性文章：
[粘贴]

以下是我自己的声音指南：
[粘贴]

请分析：
1. [目标作者] 的声音特征是什么？（用和我的声音指南相同的维度）
2. 我和他/她最大的 3 个差异是什么？
3. 哪些特征我可以学习融入我的风格中？哪些不适合我？
4. 给出一个"融合版"声音指南——保留我的核心特征，但吸收目标作者的 [具体特征]
```

## 6. 不同平台的声音变体

```
以下是我的声音指南：
[粘贴]

请为以下平台各生成一个"声音变体"——核心声音不变，但适配平台特性：

1. X (Twitter) 版：更短、更直接、更有态度
2. Newsletter 版：更深度、更个人、更对话感
3. YouTube 口播版：更口语、更有节奏、更直接对着镜头说话
4. 小红书版：更亲切、更生活感、更"有用"
5. LinkedIn 版：更职业、更故事化、更反思

每个版本 100 字以内，可直接作为该平台的 System Prompt。
```

## 7. AI 味检测 + 声音还原

```
以下是我的声音指南：
[粘贴声音指南]

以下是一段 AI 生成的内容：
[粘贴]

请：
1. 标记所有"AI 味"明显的表达（用 ~~删除线~~ 标注）
2. 标记所有"不像作者本人"的部分
3. 用作者的声音指南重写整段内容
4. 在重写中标注 [需要作者补充个人经历] 的位置
```

## 8. 声音进化追踪

```
以下是我不同时期的文章：

[早期 - 日期]：[粘贴 2 篇]
[中期 - 日期]：[粘贴 2 篇]
[近期 - 日期]：[粘贴 2 篇]

请分析我的声音演变：
1. 从早期到现在，哪些特征保持不变？（这是你的核心声音）
2. 哪些特征发生了变化？（变化方向是什么？）
3. 我的声音是变得更好了还是更差了？
4. 有没有"最近丢失了但值得找回"的早期特征？
5. 建议我在未来 3 个月有意识地强化哪些声音特征？
```
