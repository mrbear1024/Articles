# X (Twitter) 提示词模板库

---

## 1. 单条推文生成

```
请为我写一条 X 推文：

主题：[你的主题]
角度：[反常识 / 经验分享 / 数据驱动 / 提问式]
目标：[互动 / 涨粉 / 导流 Newsletter]
语气：[犀利 / 幽默 / 真诚 / 专业]

要求：
- 第一行是钩子（50字以内）
- 总长不超过 200 字
- 结尾有 CTA
- 不要用"首先/其次/此外"
- 语气像和朋友说话
```

## 2. Thread 生成

```
请为我写一条 X Thread：

主题：[你的主题]
核心论点：[一句话]
模板类型：[Before/After / Breakdown / Contrarian / Narrative / Listicle]
Thread 长度：[7-12 条]
目标受众：[画像]

要求：
- 第 1 条：强钩子，不超过 80 字，不出现"Thread"字样
- 第 2 条：告诉读者这个 Thread 的价值
- 第 3-N 条：每条独立可读，每条末尾留悬念
- 倒数第 2 条：可截图的金句
- 最后 1 条：CTA——[关注 / 转发 / 订阅 Newsletter / 评论]
- 每条 80-150 字
- 不要用"首先/其次/此外"
- 语气参考：[粘贴你的声音指南或一条满意的旧推文]
```

## 3. 钩子竞赛

```
我要写一条关于 [主题] 的推文。
请分别用以下 7 种钩子风格写开头（各 1 版，每条 50-80 字）：

1. 反常识："大多数人以为 X，但其实……"
2. 数字冲击："我用了 X 天/做了 X 件事……"
3. 故事开头：一个戏剧性场景
4. Before/After：转变对比
5. 提问式：直击痛点的问题
6. 清单预告："X 个改变我 [什么] 的 [什么]"
7. 权威引用+翻转："[名人] 说 X，但他没告诉你……"
```

## 4. 热点跟进

```
今天的热点是：[描述热点]

请帮我写 3 条和我的领域 [你的领域] 相关的推文，角度分别是：
1. 独特观点/分析
2. 从这个热点中提炼的通用经验
3. 和我的受众 [画像] 直接相关的实用建议

每条不超过 200 字，有明确立场。
```

## 5. 评论区互动（在大号下回复）

```
以下是一条来自 [大号名] 的推文：
[粘贴推文]

请帮我写 3 条"有价值的回复"——不是简单的"说得好"，而是补充一个新角度或具体经验。

要求：
- 每条 30-80 字
- 有我自己的观点或经验
- 自然地展示我在 [领域] 的专业性
- 不要显得在"蹭流量"
```

## 6. 推文改写（洗 AI 味）

```
以下是一条 AI 生成的推文初稿：
[粘贴]

请改写：
1. 删除所有"此外""值得注意的是""不可否认"等 AI 套话
2. 把"我们"改成"我"或"你"
3. 加入口语化表达
4. 如果有长句（>25字），拆成短句
5. 保持原意，但听起来像一个有态度的人在说话
```

## 7. 一周推文规划

```
我的领域是：[领域]
我的母题是：[3 个核心母题]
本周我想重点讨论：[一个话题]

请帮我规划本周 7 天的推文计划：
- 周一到周五每天 1 条推文（单条，100-200 字）
- 周三和周六各 1 条 Thread（7-10 条）
- 每天的推文类型不重复（轮换：观点/经验/数据/故事/工具/提问/清单）
- 给出每条的核心角度（一句话描述）

只给规划，不需要写全文。
```
