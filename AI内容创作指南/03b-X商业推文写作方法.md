# 模块 3b：X 商业推文写作方法

> 商业推文的目标不是"被看到"——而是"被看到之后产生行动"。
> 行动 = 点击链接 / 付费订阅 / 购买产品 / 预约咨询 / 加入社群。
> 从"有人看"到"有人付钱"之间，差的就是这一套方法。

---

## 1. 商业推文 vs 流量推文的本质区别

| 维度 | 流量推文 | 商业推文 |
|------|---------|---------|
| 目标 | 曝光、互动、涨粉 | 转化——让人做一个具体的事 |
| 指标 | 浏览量、点赞、转发 | 点击率、转化率、获客成本 |
| 读者状态 | "随便刷刷" | "我可能需要这个" |
| 内容策略 | 情绪、争议、金句 | 价值证明 + 信任建立 + 行动引导 |
| 发布频率 | 高频（日更） | 低频但精准（周 2-3 条） |

**关键认知**：商业推文不是"在推文里打广告"——而是用推文完成销售漏斗中的一个环节。

---

## 2. 商业推文的三层漏斗模型

```
第一层：认知（Awareness）
"原来有这个人/这个产品"
↓
第二层：信任（Trust）
"这个人/产品确实靠谱"
↓
第三层：行动（Action）
"我要买/订阅/预约"
```

**每一层需要不同类型的推文**——不能跳层。

一个陌生人第一次看到你就让他付费 = 失败。
他需要先经过 5-10 次"认知+信任"层的内容触达，才会在"行动"层转化。

---

## 3. 第一层推文：建立认知

### 3.1 目的

让不认识你的人：
- 知道你存在
- 知道你做什么
- 对你产生初步好奇

### 3.2 五种"认知层"推文类型

#### 类型 1：专业洞察型

展示你在领域内的判断力——不推销，只展示"我懂"。

```
示例：
"90% 的创业者在定价上犯同一个错误——
他们按成本定价，而不是按价值定价。

你的产品帮客户省了 10 万？
定价 1 万不是贵，是便宜。

定价的锚点永远是"客户得到了什么"，
不是"你花了多少成本"。"
```

**AI 提示词**：
```
我是 [身份]，帮 [客户] 解决 [问题]。
请写一条"专业洞察型"推文：
- 揭示一个大多数人犯的错误
- 给出你的正确观点
- 不提任何产品或服务
- 语气犀利但不傲慢
- 控制在 150 字以内
```

#### 类型 2：案例故事型

用真实故事展示"跟我合作/用我的方法后发生了什么"。

```
示例：
"上个月一个客户来找我，说他的 Newsletter 写了半年，只有 200 订阅者。

我看了他的内容——质量没问题。
问题在：他从来没有在 X 上推广过。

我们做了一件事：
每期 Newsletter 发布后，把核心观点拆成 1 条 Thread。

30 天后：200 → 1400。

不是内容不好。是分发有问题。"
```

**关键**：故事必须真实（或基于真实情况改编）。编造的故事一旦被识破，信任归零。

#### 类型 3：反常识观点型

挑战行业常识——引发讨论和保存。

```
示例：
"不受欢迎的观点：

大多数人不需要'内容策略'。
他们需要的是——先发 100 条推文。

策略是总结出来的，不是规划出来的。
你没有数据的时候做策略 = 纯猜。

先做量，再找模式。"
```

#### 类型 4：数据/结果展示型

用具体数字建立可信度。

```
示例：
"我的 Newsletter 数据（第 8 个月）：
- 订阅者：6,200
- 打开率：52%
- 付费转化率：4.2%
- 月收入：$2,600

最有效的增长来源：
X Thread → Newsletter 导流

最无效的：
付费广告投放

真实数据，没有美化。"
```

#### 类型 5：免费价值型

直接给出高价值信息——不收钱，但让人记住你。

```
示例：
"我帮 30+ 个创作者做过 Newsletter 增长。
最有效的 5 个策略（按效果排序）：

1. 每篇 Newsletter 配一条 X Thread
2. 在同体量 Newsletter 互相推荐
3. 做一期'年度精选'让人转发
4. 回复每一封读者邮件
5. 在结尾加'转发给一个朋友'

注意什么没在这个清单上：
付费广告。"
```

## 4. 第二层推文：建立信任

### 4.1 目的

让"已经知道你"的人：
- 相信你的专业能力
- 相信你的人品
- 对你的产品/服务产生具体兴趣

### 4.2 五种"信任层"推文类型

#### 类型 1：过程透明型

展示你的工作过程——让人看到"幕后"。

```
示例：
"今天给一个客户做 X 策略咨询。
他的情况：做 SaaS，目标是用 X 获客。

我的分析过程：
1. 先看他过去 50 条推文的数据
2. 找到互动最高的 3 条——分析共性
3. 发现他的'工具教程'比'观点输出'表现好 3 倍
4. 建议：放弃观点型，All in 教程型
5. 设计每周内容矩阵

这就是我做咨询的方式——
不是给你一个'模板'，
是帮你从你自己的数据里找到答案。"
```

#### 类型 2：客户证言型（Social Proof）

让别人说你好——比你自己说有力 100 倍。

```
示例：
"收到一条客户消息，分享一下（已授权）：

'跟你合作 2 个月后，我的 Newsletter 
从 300 涨到了 2800 订阅者。
但更重要的是——我终于知道自己在做什么了。
以前每周发 Newsletter 是焦虑的，
现在是期待的。'

这就是我想做的事——
不只是帮你涨数据，
是帮你建立一套可复制的系统。"
```

**注意**：必须是真实的、经过授权的。可以打马赛克隐去身份细节。

#### 类型 3：方法论展示型

把你的方法体系化——让人觉得"这个人有体系"。

```
示例：
"我给所有客户用的'内容增长飞轮'只有 4 步：

1. 深度内容（周更 Newsletter）
2. 分发内容（每篇拆成 Thread + 3 条短推文）
3. 导流路径（每条内容都指向订阅链接）
4. 反馈循环（数据 → 选题调整）

不复杂。复杂的是坚持做 6 个月。

大多数人在第 3 个月放弃——
恰好是飞轮开始转起来的时候。"
```

#### 类型 4："我错过/失败"型

展示脆弱性——让人觉得你是真人，不是营销机器。

```
示例：
"说一个我犯过的昂贵错误：

去年我花了 $3,000 投 X 广告推广我的课程。
结果：0 单成交。

原因很简单——
我在还没有建立信任的情况下就试图卖东西。
陌生人看到广告的第一反应是忽略，不是购买。

后来我把同样的预算投入到'免费内容+Thread'上。
6 个月后：课程卖了 $18,000。

教训：信任不能用钱买，只能用内容赚。"
```

#### 类型 5：对比/选择指南型

帮人做决定——展示你的经验广度。

```
示例：
"经常有人问我：
'我该做 Newsletter 还是做 YouTube？'

我的判断框架：
- 你更擅长写还是说？→ 擅长哪个就先做哪个
- 你的受众在哪？→ 他们读邮件多还是看视频多？
- 你的变现路径是什么？→ 课程/咨询 → Newsletter；品牌合作 → YouTube

没有'更好'的选择——
只有'更适合你现在'的选择。

如果两个都想做：先做 Newsletter，3 个月后加 YouTube。
因为文字能力是视频能力的地基。"
```

## 5. 第三层推文：引导行动

### 5.1 目的

让"已经信任你"的人采取具体行动：
- 付费订阅
- 购买产品/课程
- 预约咨询
- 加入社群

### 5.2 核心原则

**不要对冷流量发行动推文。** 行动推文只有在前两层铺垫之后才有效。

推荐比例：**认知 : 信任 : 行动 = 5 : 3 : 2**

也就是说——每发 10 条推文，只有 2 条是"卖东西"的。

### 5.3 五种"行动层"推文类型

#### 类型 1：限时/限量型

制造紧迫感——但必须是真实的。

```
示例：
"我的 1 对 1 内容策略咨询这个月还有 3 个名额。

适合你吗？
- 你已经在做自媒体 3+ 个月
- 有内容，但增长停滞
- 需要一个人帮你看数据、理清策略

60 分钟，我们一起做：
1. 审计你现有内容的数据
2. 找到你的增长瓶颈
3. 制定未来 90 天的内容计划

价格：[X]
预约链接：[链接]

名额满了就下个月见。"
```

#### 类型 2：价值证明 → CTA 型

先给一个高价值信息，然后自然过渡到 CTA。

```
示例：
"Newsletter 增长最快的方式不是写得更好——
是分发做得更聪明。

我总结了一套'一篇变十条'的分发系统：
把每期 Newsletter 拆成：
- 1 条 Thread
- 3 条短推文
- 1 条小红书
- 1 条 LinkedIn

这套系统的完整教程 + 模板，
在我的付费 Newsletter 里。

加入（$X/月）：[链接]"
```

#### 类型 3：免费 → 付费梯子型

提供一个免费的"入口产品"，引导到付费。

```
示例：
"我写了一份免费指南：
《从 0 到 1000 订阅者的 Newsletter 启动清单》

里面包含：
✓ 选定位的 4 个问题
✓ 第一期 Newsletter 的模板
✓ 发布后的 7 天推广计划
✓ 我用的工具清单

免费领取：[链接]

（如果你想要更系统的指导，
指南最后有我的课程介绍）"
```

#### 类型 4：结果导向型

直接展示"买了之后你会得到什么"。

```
示例：
"我的课程学员平均数据（开课 90 天后）：
- Newsletter 订阅者增长：+340%
- X 粉丝增长：+180%
- 内容产出频率：从月更到周更
- 有 12% 的学员开始获得付费订阅收入

不保证每个人都达到这个数字——
但我保证你会有一套清晰的系统。

下一期：[日期] 开始
详情 + 报名：[链接]"
```

#### 类型 5：Q&A / 打消顾虑型

预判潜在客户的犹豫点——主动回答。

```
示例：
"关于我的咨询服务，收到最多的 3 个问题：

Q：我粉丝很少，适合做咨询吗？
A：只要你有内容、有方向，粉丝少反而更好——试错成本低。

Q：60 分钟够吗？
A：够的。我提前看你的数据，咨询时直接给方案，不闲聊。

Q：如果咨询完没效果呢？
A：我不承诺效果——但 30 天内如果你觉得方向不对，我免费追加一次 30 分钟跟进。

还有问题？评论区问。
预约：[链接]"
```

## 6. 商业推文的节奏与排期

### 6.1 周度节奏

```
周一：认知型——专业洞察或反常识观点（引新人进来）
周二：信任型——过程透明或方法论展示
周三：认知型——免费价值型（高保存率内容）
周四：信任型——客户证言或案例故事
周五：行动型——明确 CTA 的推文
周六：信任型——"我犯过的错误"（建立人格连接）
周日：认知型——Thread（深度内容，涨粉主力）
```

### 6.2 月度节奏

```
第 1 周：铺垫——密集输出认知+信任内容
第 2 周：预热——暗示"有东西要来"（但不说明）
第 3 周：发布——产品/服务/课程发布 + 密集行动推文
第 4 周：回收——客户证言 + 数据展示 + 最后 CTA
```

### 6.3 发布前的"信任储蓄"

**规则**：在发布任何付费产品之前，你需要至少 2 周的"纯价值输出"。

想象你有一个"信任银行账户"：
- 每条价值推文 = 存入
- 每条商业推文 = 取出
- 如果余额为负 = 取关

保持"存 5 取 2"的比例。

## 7. 商业推文的文案技术

### 7.1 CTA 的写法

**差的 CTA**：
- "如果感兴趣可以了解一下"（太弱）
- "赶紧抢购！！！"（太强，像垃圾广告）
- "链接在评论区"（制造无用摩擦）

**好的 CTA**：
- 具体："预约 60 分钟咨询 → [链接]"
- 低门槛："免费领取指南 → [链接]"
- 有期限："本周五前加入 → [链接]"
- 有证据："已有 200+ 人加入 → [链接]"

### 7.2 价格呈现技术

- **锚定**：先说价值再说价格。"帮你省 10 万的方案，只收 5000。"
- **拆分**：把大数字拆成小数字。"$120/年 = 每天不到 $0.33。"
- **对比**：跟替代方案对比。"一次咨询 = 一顿火锅的钱。但火锅明天就忘了。"
- **风险逆转**："不满意 30 天内退款"——降低行动门槛。

### 7.3 "不像在卖"的卖法

最高级的商业推文，读起来不像商业推文——读起来像一条有价值的内容，只是"顺便"告诉你有个东西可以帮你。

**框架**：

```
[90% 价值内容]
↓
[自然过渡]："如果你想要完整版/更深的指导/系统化的方法……"
↓
[10% CTA]："这是链接：[X]"
```

**对比**：

```
❌ "我的课程打折了！原价 999 现价 499！快来抢！"

✅ "我花了 3 年总结出一套 Newsletter 增长方法。
    核心就是这 5 步：[列出 5 步的摘要]
    每一步的详细教程、模板、案例拆解——
    都在我的课程里。下一期 [日期] 开始：[链接]"
```

## 8. AI 辅助商业推文的工作流

### 8.1 完整流程

```
Step 1：确定本条推文在漏斗中的位置
- 是认知层/信任层/行动层？

Step 2：选择推文类型
- 从对应层的 5 种类型中选 1 种

Step 3：准备素材
- 如果是案例型：你有什么真实案例？
- 如果是数据型：你有什么可公开的数据？
- 如果是方法型：你的核心方法是什么？

Step 4：AI 生成
- 用下方提示词模板

Step 5：人工改写
- 加入你的经历细节
- 确保数据真实
- 调整语气到你的声音
- 确认 CTA 链接正确
```

### 8.2 AI 提示词模板

```
请为我写一条 X 商业推文：

我的身份：[你是谁，做什么]
我的产品/服务：[具体描述]
目标客户：[画像]
漏斗层级：[认知 / 信任 / 行动]
推文类型：[从上面的5种类型中选1种]

素材：
- [你的真实案例/数据/方法/客户反馈]

要求：
1. 不像广告，像一条有价值的推文
2. 如果有 CTA，放在最后 1-2 行
3. 语气：[犀利 / 真诚 / 专业 / 幽默]
4. 总长不超过 [200/250/300] 字
5. 如果是行动层，CTA 必须具体明确
6. 不要用感叹号表示热情
7. 不要用"赶紧""不容错过"等促销语言

我的声音指南：
[粘贴你的声音指南]
```

### 8.3 商业 Thread 模板

```
请写一条商业 Thread（7-10 条），用于 [认知/信任/行动]：

产品：[你的产品]
核心价值主张：[一句话——你帮客户做到什么]
证据：[数据/案例/方法论]

结构要求：
- 第 1 条：钩子——揭示一个问题或观点（不提产品）
- 第 2-5 条：价值内容——方法/案例/分析（不提产品）
- 第 6 条：转折——"但大多数人卡在执行"
- 第 7 条：自然引入——"这就是我做 [产品] 的原因"
- 第 8 条：具体说明产品能帮到什么
- 第 9 条：社会证明（数据/证言）
- 第 10 条：CTA + 限时/限量（如有）

关键：前 5 条完全是"纯价值"——即使读者不买任何东西，
读完前 5 条也觉得"这条 Thread 值得保存"。
```

## 9. 商业推文的常见错误

### ❌ 错误 1：每条都在卖

如果你的时间线 80% 都是"买我的东西"——取关率会爆炸。
**修正**：5:3:2 比例（认知:信任:行动）。

### ❌ 错误 2：只说"好"不说"怎么好"

"我的课程很棒！改变了很多人的人生！"—— 空洞。
**修正**：具体的人 + 具体的变化 + 具体的数字。

### ❌ 错误 3：CTA 放在评论区

"链接在评论区👇"——增加了一步摩擦，而且评论区位置不稳定。
**修正**：直接放在推文正文最后一行。X 现在允许推文内放链接。

### ❌ 错误 4：虚假的紧迫感

"最后 3 个名额！！！"但其实永远都是"最后 3 个"。
**修正**：如果用限量/限时——必须是真的。被拆穿一次，信任永远回不来。

### ❌ 错误 5：忽略"购买后"的内容

客户买了之后，你消失了——直到下次想卖东西。
**修正**：购买后持续输出价值内容，让老客户成为你的"口碑传播者"。

### ❌ 错误 6：把 X 当朋友圈用

"今天好开心，课程又卖了 10 单！🎉"
**修正**：即使分享"战报"，也要包装成对读者有价值的"复盘"——你做了什么、学到了什么。

## 10. 变现路径与产品阶梯

### 10.1 从免费到高端的产品阶梯

```
[免费内容]
  ↓ 建立认知
[免费引导产品]（指南/模板/工具清单）
  ↓ 获取邮箱/建立关系
[低价产品]（$10-50 电子书/迷你课）
  ↓ 验证付费意愿
[中价产品]（$100-500 课程/社群）
  ↓ 深度服务
[高价产品]（$1000+ 咨询/教练/Done-for-you）
  ↓ 高端变现
```

### 10.2 每一层对应的推文策略

| 产品层级 | 推文目标 | 推文类型 |
|----------|---------|---------|
| 免费引导产品 | 获取邮箱 | 免费价值型 + 简单 CTA |
| 低价产品 | 广撒网，低门槛 | 结果导向型 + 价格拆分 |
| 中价产品 | 建立信任后推 | 案例证言 + 方法论 + 限时 |
| 高价产品 | 精准触达 | 1对1 DM + 过程透明 + Q&A |

## 11. 数据追踪与优化

### 11.1 商业推文的关键指标

| 指标 | 含义 | 健康范围 |
|------|------|---------|
| 链接点击率 | 点击/曝光 | > 1% 为佳 |
| 转化率 | 购买/点击 | 取决于产品（2-10%） |
| CPA（获客成本） | 每获得一个客户的推文数量 | 追踪趋势 |
| Thread 完成率 | 读到最后一条的比例 | > 30% |
| 保存率 | 保存/曝光 | > 0.5% |

### 11.2 优化循环

```
每周回顾：
1. 哪条商业推文表现最好？（点击率+转化率）
2. 分析为什么——是钩子好？是案例有力？是CTA 清晰？
3. 下周多做这类推文
4. 哪条表现最差？为什么？停止做这类
```
