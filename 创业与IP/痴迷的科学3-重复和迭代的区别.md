# 重复和迭代的区别：为什么努力了很久却毫无长进

Ericsson 用了几十年研究"刻意练习"（Deliberate Practice），他最重要的发现是一个残酷的事实：**没有反馈的练习，无论重复多少次，都不会带来进步。**

这解释了为什么很多人"努力了很久"却毫无长进——他们在重复，但从未迭代。重复是做同样的事一千次；迭代是做一千次不同的事，每一次都比上一次好一点。

两者的分界线在于**反馈**。

你发了一条推文，不看数据，不分析为什么好、为什么差，然后发下一条——这是重复。你发了一条推文，花十分钟分析数据，发现"带具体数字的标题互动率高30%"，然后下一条立刻用上——这是迭代。

Ericsson 的研究明确指出，刻意练习有四个必要条件：明确的目标（比如"互动率从2%提到5%"）、即时的反馈（每条推文几小时后就有数据）、在舒适区边缘挑战（每次尝试一个新变量）、以及高度专注。

当迭代足够密集，另一种状态会出现。

心理学家 Mihaly Csikszentmihalyi 花了三十年研究的**心流**（Flow）——一种完全沉浸、忘记时间的状态——恰恰需要同样的条件：目标清晰、反馈即时、难度与能力匹配。

Edward Deci 和 Richard Ryan 的"自我决定理论"也指出：**自主感**（我自己选择做）、**胜任感**（我越来越擅长）和**关联感**（有人在看）能让内在动机自然涌现。

一旦进入心流，"坚持"就成了一个多余的词。没有人需要自律才能打游戏——你会自动打开X看数据，因为你已经上瘾了。

痴迷的本质，就是心流成为了你的默认状态。
