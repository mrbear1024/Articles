# 02 注册 Apple 开发者账号

先说一个容易混淆的事实：用一个普通的 Apple ID，你今天就能免费写 iOS App，甚至能装到自己的 iPhone 上跑。但这个免费额度有两个致命限制——装到真机上的 App 七天后就会失效，而且永远无法上架 App Store。

所以「Apple 开发者账号」这个词，实际指的是付费加入 Apple Developer Program：99 美元一年，换来发布资格、TestFlight、App 分析后台和一整套分发能力。

这一章帮你把这个账号办下来，并避开几个会拖慢你一两周的坑。

---

## 一、先准备好一个「干净」的 Apple ID

注册开发者账号的第一步是登录 Apple ID。对这个 Apple ID 有几条硬要求：

- **必须开启双重认证。** 没开的话去 iPhone 的「设置 → 你的名字 → 登录与安全」里打开，这是注册的前置条件
- **姓名必须是你的真实法定姓名。** 苹果会校验身份，Apple ID 里填昵称、英文名、网名的，注册时会被卡住。先去 [appleid.apple.com](https://appleid.apple.com) 把姓名改成与身份证一致
- **建议用你长期持有的邮箱。** 这个账号未来会绑定你所有的 App、收入和证书，不要用临时邮箱或公司邮箱

如果你的主力 Apple ID 信息混乱，另注册一个专门用于开发的 Apple ID 是完全可行的做法，很多独立开发者都这么干。

## 二、个人账号还是公司账号

Apple Developer Program 有两种主体类型，注册前必须选定：

| 维度 | 个人（Individual） | 组织（Organization） |
|------|------|------|
| 年费 | 99 美元 | 99 美元 |
| App Store 显示的开发者名 | 你的真实姓名 | 公司名称 |
| 注册材料 | 身份证件 | 营业执照 + D-U-N-S 编号 |
| 注册耗时 | 1~3 天 | 2~4 周 |
| 团队协作 | 不支持多人 | 支持团队成员管理 |
| 收款主体 | 个人银行账户 | 公司银行账户 |

**第一个 App，选个人账号。** 理由很简单：快，材料少，99 美元一分不多。唯一的代价是 App Store 页面上「开发者」一栏显示你的真实姓名——如果你介意这一点，且名下有公司，再考虑组织账号。

组织账号需要 D-U-N-S 编号（邓白氏编码），这是一个免费但流程冗长的企业身份编号，申请加核验通常要两周起步。除非你明确需要公司主体收款或多人协作，否则别在第一个 App 上消耗这个时间。

## 三、注册流程：推荐走 Apple Developer App

注册有两条路：网页（developer.apple.com）和 iPhone 上的 Apple Developer App。**强烈推荐用 App 注册**，因为身份验证环节需要拍摄身份证件和人脸识别，App 内一气呵成，网页流程反而绕。

**第一步，在 iPhone 上下载 Apple Developer App。** App Store 搜「Apple Developer」，苹果官方出品的那个。

**第二步，登录并进入注册流程。** 打开 App，底部切到「账户」标签，登录你准备好的 Apple ID，点「立即注册」（Enroll Now）。

**第三步，身份验证。** 选择「个人」类型后，App 会要求拍摄身份证件正反面，然后做一次人脸扫描。光线充足、证件信息清晰，一般几分钟内通过。

**第四步，付款。** 中国区价格为 688 元/年（即 99 美元的本地定价），用 App 内购买的方式支付，支持你 Apple ID 绑定的任何付款方式。注意这笔钱开通后不可退（部分地区法规例外）。

**第五步，等待激活邮件。** 付款后账号通常在 48 小时内激活，你会收到一封「Welcome to the Apple Developer Program」邮件。收到它，你就正式有了发布资格。

## 四、常见的卡点和解法

**付款后超过 48 小时没激活。** 不少见。直接去 developer.apple.com/contact 联系支持，中文电话支持响应很快，通常一个电话就能查到卡在哪。

**身份验证反复失败。** 九成是 Apple ID 姓名与证件不一致，回到第一节检查。剩下一成是证件照片反光或裁切，换个环境重拍。

**「该 Apple ID 已关联其他开发者账号」。** 这个 Apple ID 可能曾被拉进过别人的开发团队。退出原团队，或者换一个 Apple ID 注册。

**未满 18 岁。** 个人开发者账号要求年满 18 岁，未成年人只能用监护人身份注册，App 也归属在监护人名下。

## 五、激活之后：认识你的两个后台

账号激活后，你会和两个网站长期打交道，先分清它们的职责：

- **developer.apple.com** —— 管「资格」：证书、标识符（Bundle ID）、描述文件、设备注册。第五章的主战场
- **appstoreconnect.apple.com** —— 管「产品」：创建 App、填元数据、传构建版本、看销售数据、回复用户评论。第六章之后的主战场

现在登录 App Store Connect 看一眼。如果能看到「我的 App」「TestFlight」「协议、税务和银行业务」这些入口，说明账号一切正常。

顺手做一件事：进入「协议、税务和银行业务」，把「付费 App 协议」（Paid Applications Agreement）签了。即使你的第一个 App 完全免费，这份协议也建议提前签——等你哪天想加内购，不用临时等协议生效。

## 写在最后

99 美元买到的东西，比表面上多：全球 175 个区的分发、TestFlight 的一万个测试名额、崩溃日志收集、销售分析后台，以及给 App 公证（Notarization）的资格。按月摊下来不到 60 块人民币，是整个独立开发链路里性价比最高的一笔支出。
