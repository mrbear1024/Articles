## 什么是小龙虾？

小龙虾，正式名称 **OpenClaw**，是一个开源的**多渠道 AI Agent 网关平台**。

它跟 ChatGPT 网页版最大的区别是：ChatGPT 只能在浏览器里跟你聊天，而小龙虾可以把 AI Agent 接入你日常使用的 **20 多个通讯平台**——飞书、企业微信、钉钉、微信、Telegram、Discord、Slack、Teams 等。

更关键的是，小龙虾里的 AI 不只是"回答问题"。它可以**执行任务**：自动浏览网页、操作文件、发送跨平台消息、记住你的偏好和上下文。它是一个真正的 AI 助手，而不仅仅是一个聊天机器人。

**一句话总结：** 小龙虾让你在任何聊天软件里，拥有一个能干活的私人 AI 助手。

## 第一步：选设备

### 我需要什么样的设备？

小龙虾本身很轻量，对硬件要求不高。但你的选择取决于**使用场景**。

#### 场景一：个人玩玩，偶尔用

**推荐：用你现有的笔记本电脑就行。**

最低要求：
- 内存：4GB（建议 8GB）
- 硬盘：至少 2GB 空闲空间
- CPU：不挑，近五年的电脑都没问题

MacBook、Windows 笔记本、Linux 笔记本都可以。唯一的缺点是：笔记本合盖或关机后，AI 助手就下线了。

#### 场景二：希望 AI 助手 24 小时在线

**推荐：Mac Mini 或一台便宜的云服务器。**

**Mac Mini（适合家用）：**
- 优点：安静、省电、macOS 体验好、性能强
- 缺点：需要家里有稳定的网络
- 推荐配置：M1/M2 芯片，8GB 内存，256GB 硬盘（二手 2000 元左右就能搞定）

**云服务器 VPS（适合随时随地访问）：**

| 平台 | 最低价格 | 适合场景 |
|---|---|---|
| Hetzner | 约 35 元/月 | 性价比最高，欧洲节点 |
| DigitalOcean | 约 45 元/月 | 操作简单，新加坡节点 |
| Railway | 免费额度起步 | 一键部署，最省心 |
| Oracle Cloud | 永久免费层 | 零成本入门 |

> **小白建议：** 如果你只是想体验一下，用自己的笔记本就够了。等确定要长期用了，再考虑 Mac Mini 或 VPS。

#### 各设备对比一览

| 设备 | 成本 | 24 小时运行 | 上手难度 | 推荐指数 |
|---|---|---|---|---|
| 现有笔记本 | 0 元 | ❌ | ⭐ | 体验入门 |
| Mac Mini | 2000-4000 元 | ✅ | ⭐⭐ | 个人长期使用 |
| 云服务器 VPS | 35-100 元/月 | ✅ | ⭐⭐⭐ | 随时随地访问 |
| 树莓派 | 300-500 元 | ✅ | ⭐⭐⭐⭐ | 极客玩法 |

## 第二步：选操作系统

### macOS（推荐指数：⭐⭐⭐⭐⭐）

小龙虾在 macOS 上体验最好。有原生应用、菜单栏集成、语音覆盖层支持。

如果你用的是 MacBook 或 Mac Mini，直接在 macOS 上安装就行，不需要折腾其他东西。

### Linux（推荐指数：⭐⭐⭐⭐⭐）

生产环境首选。如果你用云服务器，基本都是 Linux。推荐 **Ubuntu 22.04 LTS** 或更新版本——社区资料最多，遇到问题最容易找到答案。

### Windows（推荐指数：⭐⭐⭐）

Windows 不能直接运行小龙虾，需要先安装 **WSL2**（Windows Subsystem for Linux）。WSL2 本质上是在 Windows 里运行一个 Linux 环境。

**安装 WSL2 的步骤：**

1. 以管理员身份打开 PowerShell
2. 运行：
```powershell
wsl --install
```
3. 重启电脑
4. 打开 Microsoft Store，安装 Ubuntu 22.04
5. 启动 Ubuntu，设置用户名和密码

之后所有操作都在 WSL2 的 Ubuntu 终端里进行，跟 Linux 一模一样。

> **Windows 用户注意：** 后面教程里的所有命令，都在 WSL2 的 Ubuntu 终端中执行，不是在 PowerShell 或 CMD 里。

## 第三步：安装 Node.js

小龙虾基于 Node.js 运行，需要 **Node.js 22.0 或更高版本**。

### 检查是否已安装

打开终端（macOS 的 Terminal，Linux 的终端，或 Windows 的 WSL2 Ubuntu），输入：

```bash
node --version
```

如果显示 `v22.x.x` 或更高，可以跳过这一步。如果提示"command not found"或版本太低，继续往下看。

### macOS 安装 Node.js

**方法一：使用 Homebrew（推荐）**

如果没装过 Homebrew，先装它：
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

然后安装 Node.js：
```bash
brew install node@22
```

**方法二：使用 nvm（版本管理器）**

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

关闭终端，重新打开，然后：
```bash
nvm install 22
nvm use 22
```

### Linux（Ubuntu/Debian）安装 Node.js

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
```

### 验证安装

```bash
node --version   # 应该显示 v22.x.x
npm --version    # 应该显示 10.x.x 或更高
```

## 第四步：安装 OpenClaw

### 方法一：一键安装（推荐新手使用）

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

这个脚本会自动完成下载、编译和安装。

### 方法二：从源码安装（适合想深入了解的人）

```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw
npm install
npm run build
npm link
```

### 安装完成后：运行初始化向导

这一步非常关键。运行：

```bash
openclaw onboard --install-daemon
```

向导会一步步引导你完成以下配置：

1. **选择 AI 模型提供商** —— Kimi（月之暗面）、Anthropic（Claude）、OpenAI 等
2. **输入 API Key** —— 填入你的密钥（后面会详细讲怎么获取）
3. **选择默认模型** —— 比如 Kimi（moonshot-v1-128k）
4. **初始化工作目录** —— 自动创建 `~/.openclaw/workspace/`
5. **连接聊天平台** —— 选择你要接入的平台（飞书、企业微信、钉钉等）
6. **安全配置** —— 设置谁可以跟你的 AI 助手对话

> **跟着向导走就行**，每一步都有提示。如果不确定某个选项，先选默认值，之后随时可以改。

### 验证安装成功

```bash
openclaw gateway status
openclaw health
```

如果一切正常，你会看到网关状态为"running"。打开浏览器访问 `http://127.0.0.1:18789/`，应该能看到控制台界面。

## 第五步：网络环境配置

### 基本原理

小龙虾的网络模型很简单：

```
你的设备 ──向外连接──> 各个平台的 API（Telegram、OpenAI 等）
```

它只需要**向外发起连接**，不需要你的设备能被外网访问。也就是说：
- ✅ 不需要公网 IP
- ✅ 不需要开放端口
- ✅ 不需要域名
- ✅ 家用宽带就能用

### 默认端口

| 端口 | 用途 |
|---|---|
| 18789 | 控制台网页界面 |
| 18790 | WebSocket 内部通信 |
| 18800-18899 | 浏览器自动化实例 |

这些端口默认只监听 `127.0.0.1`（本机），外部无法访问，非常安全。

### 如果你在国内使用

因为小龙虾需要访问 Anthropic、OpenAI、Telegram 等境外服务，你需要确保网络能正常访问这些地址。

常见的解决方案：

**方案一：在路由器层面配置代理**（推荐，一劳永逸）

如果你的路由器支持透明代理（比如刷了 OpenWrt），在路由器上配好代理规则，设备不需要做任何额外设置。

**方案二：在系统层面配置代理**

设置环境变量：
```bash
export https_proxy=http://127.0.0.1:7890
export http_proxy=http://127.0.0.1:7890
export all_proxy=socks5://127.0.0.1:7890
```

可以把这几行加到 `~/.bashrc` 或 `~/.zshrc` 文件末尾，这样每次打开终端都自动生效。

**方案三：使用支持国内直连的 API 中转**

部分第三方平台提供国内可直连的 API 中转服务（如 OpenRouter），可以免去代理配置的麻烦。

### 远程访问你的小龙虾（可选）

如果你把小龙虾装在家里的 Mac Mini 上，但想在外面也能管理它：

**推荐方案：Tailscale（最简单、最安全）**

1. 在 Mac Mini 和你的手机/笔记本上都安装 Tailscale
2. 用同一个账号登录
3. 通过 Tailscale 分配的内网 IP 访问控制台

```bash
# 安装 Tailscale（macOS）
brew install tailscale

# 启动并登录
tailscale up
```

这样你在外面也能通过 `http://100.x.x.x:18789/` 访问你的小龙虾控制台。

### 安全提醒

**绝对不要**把小龙虾的端口直接暴露到公网：

```json
// ❌ 危险！不要这样做
{ "gateway": { "bind": "0.0.0.0" } }
```

```json
// ✅ 正确做法：只监听本机
{
  "gateway": {
    "bind": "loopback",
    "auth": { "mode": "token", "token": "你的安全令牌" }
  }
}
```

## 第六步：接入 AI 模型（OAuth 与 API Key）

小龙虾本身不包含 AI 模型，它需要连接外部的模型服务。你可以同时接入多个模型，让它们互相备份。

### 支持的模型提供商

**国内可直连（推荐优先使用）：**

| 提供商 | 推荐模型 | 价格区间 | 接入方式 |
|---|---|---|---|
| **Kimi（月之暗面）** | moonshot-v1-128k | 12-60 元/百万 token | API Key |
| **智谱 AI** | GLM-4 | 5-100 元/百万 token | API Key |
| **百度文心** | ERNIE-4.0 | 12-120 元/百万 token | API Key |
| **通义千问** | Qwen-Max | 2-20 元/百万 token | API Key |
| **DeepSeek** | DeepSeek-V3 | 1-8 元/百万 token | API Key |

**海外模型（需要代理或中转）：**

| 提供商 | 推荐模型 | 价格区间 | 接入方式 |
|---|---|---|---|
| **Anthropic** | Claude Opus/Sonnet | 约 20-110 元/百万 token | API Key 或 OAuth |
| **OpenAI** | GPT-4o / GPT-5 | 约 18-110 元/百万 token | API Key 或 OAuth |
| **Google** | Gemini 2.5 Pro | 约 9-73 元/百万 token | API Key |
| **OpenRouter** | 多模型聚合 | 按模型计费 | API Key |

**本地模型（免费）：**

| 提供商 | 推荐模型 | 价格 | 接入方式 |
|---|---|---|---|
| **Ollama** | Llama / Qwen 等 | 免费（需本地算力） | 无需认证 |

> **国内用户强烈推荐：** 优先使用 Kimi。无需代理、国内直连、中文能力强、128k 超长上下文、注册简单。等熟悉了再考虑接入其他模型做备份。

### 方式一：API Key 接入（最常用）

以 **Kimi（月之暗面）** 为例，国内直连，最适合新手：

**第 1 步：获取 Kimi API Key**

1. 打开 [platform.moonshot.cn](https://platform.moonshot.cn)
2. 用手机号注册/登录
3. 进入「API 管理」页面
4. 点击「创建 API Key」
5. 复制生成的密钥（以 `sk-` 开头）

> ⚠️ API Key 只显示一次，复制后妥善保存。新注册用户通常有免费额度，可以先体验。

**第 2 步：配置到小龙虾**

方法 A——通过环境变量（推荐）：

创建或编辑 `~/.openclaw/.env` 文件：
```bash
MOONSHOT_API_KEY=sk-xxxxx你的密钥xxxxx
```

方法 B——通过配置文件：

编辑 `~/.openclaw/openclaw.json`：
```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "moonshot/moonshot-v1-128k",
        "fallbacks": ["deepseek/deepseek-chat", "qwen/qwen-max"]
      }
    }
  }
}
```

**第 3 步：重启网关使配置生效**

```bash
openclaw gateway restart
```

> **其他国内模型的 API Key 获取方式类似：**
> - **DeepSeek：** 访问 [platform.deepseek.com](https://platform.deepseek.com)，注册后创建 API Key
> - **智谱 AI：** 访问 [open.bigmodel.cn](https://open.bigmodel.cn)，注册后获取
> - **通义千问：** 访问 [dashscope.aliyun.com](https://dashscope.aliyun.com)，用阿里云账号登录

### 方式二：OAuth 授权接入（海外模型）

如果你需要使用海外模型（需代理），OAuth 可以免去手动管理 API Key 的麻烦：

**Anthropic OAuth 接入：**

```bash
claude setup-token
openclaw models auth setup-token --provider anthropic
```

**OpenAI OAuth 接入：**

```bash
openclaw onboard --oauth openai
```

系统会自动打开浏览器，引导你登录对应账号并授权。完成后令牌自动保存。

> 国内用户如果网络条件不方便，跳过这一步，直接用 Kimi 等国内模型即可。

### 方式三：本地模型（Ollama，完全免费）

如果你的设备性能不错（8GB 以上内存），可以跑本地模型，完全不花 API 费用：

```bash
# 安装 Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 下载一个模型
ollama pull llama3.1

# 在小龙虾配置中使用
```

在 `openclaw.json` 中配置：
```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "ollama/llama3.1"
      }
    }
  }
}
```

### 模型故障自动切换

小龙虾支持配置多个模型，当主力模型不可用时（比如 API 欠费、服务宕机），会自动切换到备用模型：

```json
{
  "model": {
    "primary": "moonshot/moonshot-v1-128k",
    "fallbacks": [
      "deepseek/deepseek-chat",
      "qwen/qwen-max"
    ]
  }
}
```

> 上面的配置全部是国内模型，无需代理即可使用。

## 第七步：连接你的聊天平台

小龙虾的核心能力是把 AI 助手接入你日常使用的聊天软件。国内用户推荐优先接入飞书或企业微信。

### 飞书（推荐国内用户首选）

飞书是国内团队协作最主流的平台之一，接入后你可以在飞书里直接跟 AI 助手对话。

**第 1 步：创建飞书自建应用**

1. 打开 [飞书开放平台](https://open.feishu.cn/)，用飞书账号登录
2. 点击「创建企业自建应用」
3. 填写应用名称（比如"小龙虾助手"）和描述，点击确定
4. 进入应用详情页，记录下 **App ID** 和 **App Secret**

**第 2 步：配置机器人能力**

1. 在应用详情页，左侧点击「添加应用能力」→ 勾选「机器人」
2. 进入「事件与回调」→「事件配置」，添加以下事件：
   - `im.message.receive_v1`（接收消息）
3. 设置请求地址（Webhook URL），格式为：`http://你的服务器地址:18789/webhook/feishu`
4. 进入「权限管理」，开通以下权限：
   - `im:message`（发送消息）
   - `im:message.receive`（接收消息）

**第 3 步：配置到小龙虾**

```bash
openclaw channel add feishu \
  --app-id "cli_xxxxxx" \
  --app-secret "你的AppSecret"
```

或在 `openclaw.json` 中手动添加：

```json
{
  "channels": {
    "feishu": {
      "enabled": true,
      "appId": "cli_xxxxxx",
      "appSecret": "你的AppSecret"
    }
  }
}
```

**第 4 步：发布应用**

1. 回到飞书开放平台，点击「版本管理与发布」
2. 创建版本并提交审核（企业内部应用一般秒过）
3. 审核通过后，在飞书中搜索你的机器人名称，发一条消息测试

> **提示：** 如果是个人开发者测试，可以先用「测试企业」功能，不需要真实企业审核。

### 企业微信

企业微信适合已有企业微信团队的场景。

**第 1 步：创建企业微信应用**

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/)
2. 进入「应用管理」→「自建应用」→「创建应用」
3. 记录下 **CorpID**、**AgentId** 和 **Secret**

**第 2 步：配置到小龙虾**

```bash
openclaw channel add wecom \
  --corp-id "你的CorpID" \
  --agent-id "1000002" \
  --secret "你的Secret"
```

**第 3 步：设置回调地址**

在企业微信后台设置接收消息的 API 地址，指向你的小龙虾服务。

### 钉钉

**第 1 步：创建钉钉机器人**

1. 登录 [钉钉开放平台](https://open.dingtalk.com/)
2. 创建企业内部应用，添加「机器人」能力
3. 获取 **AppKey** 和 **AppSecret**

**第 2 步：配置到小龙虾**

```bash
openclaw channel add dingtalk \
  --app-key "你的AppKey" \
  --app-secret "你的AppSecret"
```

### 微信个人号（实验性）

通过 Web 协议接入个人微信，适合个人使用场景：

```bash
openclaw channel add wechat
```

系统会显示一个二维码，用微信扫码登录即可。

> ⚠️ **注意：** 个人微信接入属于非官方方式，存在封号风险，建议使用小号测试。正式场景请使用企业微信或飞书。

### Telegram（海外用户推荐）

如果你也使用 Telegram，它是海外最容易接入的平台：

1. 在 Telegram 中搜索 **@BotFather**，发送 `/newbot`
2. 按提示创建机器人，获得 Bot Token
3. 配置：

```bash
openclaw channel add telegram --token "你的Bot Token"
```

### 会话隔离模式

如果你的 AI 助手会跟多个人对话，一定要配置会话隔离，防止信息串台：

| 模式 | 说明 | 适用场景 |
|---|---|---|
| `main` | 所有对话共享同一个上下文 | 仅自己使用 |
| `per-peer` | 每个用户独立上下文 | 多人使用，单平台 |
| `per-channel-peer` | 每个平台的每个用户独立 | 多人使用，多平台 |

在 `openclaw.json` 中设置：
```json
{
  "session": {
    "scope": "per-peer"
  }
}
```

## 第八步：安装技能

技能（Skills）是小龙虾的扩展模块，让 AI 助手获得更多能力。

### 查看可用技能

```bash
openclaw skills list
```

### 内置技能分类

| 分类 | 技能示例 | 能做什么 |
|---|---|---|
| **信息获取** | web-research、summarize、translate | 搜索网页、总结内容、翻译 |
| **浏览器自动化** | browser-auto、form-filler | 自动填表、抓取网页数据 |
| **生产力** | email、calendar、todo | 管理邮件、日历、待办事项 |
| **语音** | whisper、tts | 语音转文字、文字转语音 |
| **媒体处理** | image-analysis、video-summary | 图片识别、视频总结 |
| **通讯** | telegram-post、slack-webhook | 跨平台发送消息 |
| **开发** | code-executor、github-api | 执行代码、操作 GitHub |

### 安装技能的三种方式

**方式一：命令行安装（推荐）**

```bash
# 安装一个技能
openclaw skills install web-research

# 启用它
openclaw skills enable web-research
```

**方式二：通过控制台网页安装**

1. 打开浏览器，访问 `http://127.0.0.1:18789/`
2. 点击左侧菜单的"Skills"（技能）
3. 浏览技能列表，点击"Enable"（启用）

**方式三：直接跟 AI 说**

在聊天中告诉你的 AI 助手：

> "帮我启用 web-research 技能，我需要你能搜索网页。"

### 新手推荐的入门技能组合

1. **web-research** —— 让 AI 能搜索互联网，获取最新信息
2. **summarize** —— 总结长文、网页内容
3. **translate** —— 多语言翻译
4. **todo** —— 待办事项管理

```bash
# 一次性安装这几个
openclaw skills install web-research summarize translate todo
openclaw skills enable web-research summarize translate todo
```

## 第九步：使用技能

技能安装并启用后，你只需要在聊天中自然地描述需求，AI 会自动调用对应的技能。

### 使用示例

**网页搜索：**
> 你："帮我查一下最新的 iPhone 17 发布时间和价格。"
>
> AI 会自动调用 web-research 技能，搜索网页并返回结果。

**内容总结：**
> 你："总结一下这篇文章的要点：https://example.com/article"
>
> AI 会自动获取文章内容，然后用 summarize 技能生成摘要。

**翻译：**
> 你："把下面这段话翻译成英文：今天天气真不错。"
>
> AI 调用 translate 技能完成翻译。

**待办事项：**
> 你："帮我记一下，明天下午三点开产品评审会。"
>
> AI 调用 todo 技能记录待办。

### 管理已安装的技能

```bash
# 查看已安装和启用的技能
openclaw skills status

# 禁用某个技能
openclaw skills disable browser-auto

# 从硬盘重新加载所有技能
openclaw skills reload
```

### 创建你自己的技能

技能文件存放在 `~/.openclaw/workspace/skills/` 目录下。每个技能就是一个 Markdown 文件，描述这个技能能做什么、怎么做。

一个最简单的自定义技能：

```markdown
# 日报生成器

根据今天的聊天记录，自动生成工作日报。

## 触发条件
当用户说"生成日报"或"写日报"时触发。

## 执行步骤
1. 回顾今天的所有对话记录
2. 提取关键的工作事项
3. 按"已完成"和"进行中"分类
4. 生成格式化的日报

## 输出格式
使用 Markdown 格式，包含日期、工作事项列表和明日计划。
```

把这个文件保存为 `~/.openclaw/workspace/skills/daily-report.md`，然后：

```bash
openclaw skills reload
openclaw skills enable daily-report
```

之后在聊天中说"帮我写日报"，AI 就会按照你定义的规则执行。

## 新手常见问题 FAQ

### Q1：安装时提示"command not found: openclaw"

**原因：** 安装脚本的路径没有加入系统 PATH。

**解决：**
```bash
# 查看 openclaw 安装在哪里
which openclaw

# 如果没有找到，尝试手动添加路径
export PATH="$HOME/.openclaw/bin:$PATH"

# 加到配置文件里永久生效
echo 'export PATH="$HOME/.openclaw/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### Q2：网关启动失败，提示端口被占用

**原因：** 端口 18789 已经被其他程序占用了。

**解决：**
```bash
# 查看谁占用了端口
lsof -i :18789

# 方法一：关掉占用端口的程序
kill <PID>

# 方法二：改用其他端口
# 编辑 ~/.openclaw/openclaw.json
{
  "gateway": {
    "port": 18800
  }
}
```

### Q3：AI 不回复消息

按以下顺序排查：

1. **检查网关是否运行中：**
```bash
openclaw gateway status
```

2. **检查 API Key 是否有效/有余额：**
   - 登录对应平台的控制台，查看余额和用量

3. **查看日志找具体报错：**
```bash
openclaw logs --follow
```

4. **检查网络是否能访问 API 服务：**
```bash
curl https://api.anthropic.com/v1/messages -I
```

### Q4：在国内访问不了 Anthropic/OpenAI 的 API

**解决方案优先级：**

1. **路由器层面代理**（最优）—— 全局透明代理，所有设备自动生效
2. **终端代理**——设置 `https_proxy` 环境变量
3. **用 OpenRouter 中转**——国内部分网络可以直连 OpenRouter

### Q5：Telegram Bot 创建了但收不到消息

**排查清单：**

- 是否在 Telegram 中给 Bot 发了 `/start`？（必须先发这个命令）
- Bot Token 是否正确复制了？（注意前后不要有空格）
- 网关是否在运行中？

### Q6：API 费用太高怎么办？

**省钱技巧：**

| 策略 | 预期节省 |
|---|---|
| 使用 Ollama 本地模型（需 8GB+ 内存） | 100%，完全免费 |
| 选用 Claude Haiku 或 GPT-4o-mini 等小模型 | 节省 80-90% |
| 配置会话压缩，减少上下文长度 | 节省 30-50% |
| 只在需要时启用昂贵的技能（如浏览器自动化） | 视使用频率而定 |

**不同使用强度的月费参考：**

| 使用强度 | 服务器费 | API 费 | 总计/月 |
|---|---|---|---|
| 轻度（每天聊几次） | 0 元（用自己电脑） | 30-70 元 | 30-70 元 |
| 中度（日常助手） | 35-45 元（VPS） | 100-200 元 | 135-245 元 |
| 重度（团队/自动化） | 70-150 元（VPS） | 200-700 元 | 270-850 元 |

### Q7：浏览器自动化技能在云服务器上不工作

**原因：** 云服务器通常没有图形界面（headless 环境），浏览器需要额外配置。

**解决：**
```bash
# 安装 Chromium 和中文字体（Ubuntu）
sudo apt install -y chromium-browser fonts-noto-cjk

# 或者使用 Browserless 容器（推荐）
docker run -p 3000:3000 ghcr.io/browserless/chromium
```

然后在配置中指定远程浏览器：
```json
{
  "tools": {
    "browser": {
      "profiles": {
        "vps": { "cdpUrl": "ws://localhost:3000" }
      },
      "defaultProfile": "vps"
    }
  }
}
```

### Q8：内存占用太高怎么办？

- 浏览器自动化是内存大户，不用的时候可以关掉对应技能
- 每个并发 Agent 大约占用 50-100MB 内存
- 如果是低内存的 VPS，建议增加 Swap 空间：

```bash
sudo fallocate -l 4G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
```

### Q9：如何升级小龙虾？

```bash
# 一键安装版
curl -fsSL https://openclaw.ai/install.sh | bash

# 源码安装版
cd openclaw
git pull
npm install
npm run build
```

### Q10：数据存在哪里？怎么备份？

| 路径 | 内容 |
|---|---|
| `~/.openclaw/openclaw.json` | 主配置文件 |
| `~/.openclaw/.env` | 环境变量（API Key 等） |
| `~/.openclaw/agents/` | Agent 数据、会话记录、记忆 |
| `~/.openclaw/workspace/` | Agent 的工作目录 |
| `~/.openclaw/gateway/` | 网关状态、配对信息 |

**备份建议：** 定期备份整个 `~/.openclaw/` 目录即可：

```bash
tar -czf openclaw-backup-$(date +%Y%m%d).tar.gz ~/.openclaw/
```

### Q11：万能急救命令

如果什么都试了还是不行：

```bash
# 自动诊断并修复
openclaw doctor --fix

# 查看实时日志
openclaw logs --follow

# 重启网关
openclaw gateway restart
```
