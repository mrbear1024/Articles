# 注册美区 Apple ID 完整教程

注册美区 Apple ID 的核心要点是：**全程使用美国信息，不绑定任何支付方式**。

---

## 准备工作

- 一个没有注册过 Apple ID 的邮箱（推荐 Gmail 或 Outlook）
- 一个**美国手机号**用于验证（国内号码现已不可用，见下方获取方法）

### 如何免费获取美国手机号

推荐使用 **TextNow**，免费提供美国虚拟号码，可接收短信。

1. 在手机上下载 **TextNow** App（需要先有一个美区 Apple ID，或用 Android 在 Google Play 下载）
2. 注册 TextNow 账号（邮箱注册即可）
3. 注册完成后会自动分配一个美国号码，记下这个号码备用

> 如果还没有美区 Apple ID 来下载 TextNow，可以先用 Android 手机或电脑浏览器版 TextNow 获取号码。电脑浏览器版地址：textnow.com

---

## 注册步骤

### 第一步：在浏览器中打开注册页面

用浏览器访问 Apple ID 创建页面：

```
https://appleid.apple.com/account
```

> 注意：不要在手机设置里直接创建，浏览器注册可以直接选择国家，更可控。

---

### 第二步：填写账号基本信息

| 字段 | 填写说明 |
|------|----------|
| 名字/姓氏 | 填英文名，随意，如 John Smith |
| 国家/地区 | 选择 **United States** |
| 出生日期 | 填写成年日期即可（如 1990/01/01） |
| 邮箱 | 填写你准备好的邮箱，这就是账号名 |
| 密码 | 至少 8 位，含大小写字母和数字 |

填完点击 **继续**。

---

### 第三步：验证邮箱

Apple 会向你填写的邮箱发送一封验证邮件，里面有 6 位验证码。

打开邮箱，找到来自 Apple 的邮件，填入验证码后点击继续。

---

### 第四步：验证手机号

输入你在 TextNow 获取的美国号码（+1 开头），Apple 会发送短信验证码。

打开 TextNow App，在收件箱中查收短信，填入验证码后继续。

---

### 第五步：登录并切换到美区 App Store

Apple ID 注册完成后，需要在 **App Store** 中激活为美区账户：

1. 打开 iPhone 上的 **App Store**
2. 点击右上角头像 → 滚动到底部 → **退出登录**
3. 重新登录，输入刚注册的新 Apple ID
4. 登录后系统会提示 **"此 Apple ID 尚未在 iTunes Store 使用过"**，点击 **检查**

---

### 第六步：填写美国地址信息（关键步骤）

进入地址填写页面后：

- **付款方式**：选择 **None（无）**
- **账单地址**：填写一个美国地址

推荐使用免税州地址，避免产生额外税费，可从下面直接复制：

**Oregon（俄勒冈州）示例地址：**

```
Street: 4600 NE Hassalo St
City: Portland
State: OR
Zip Code: 97213
Phone: 503-288-1501
```

> 这是一个真实存在的公共地址（购物中心），用于注册合法。不要填写私人住宅地址。

填完后点击 **下一步**，美区 App Store 账户激活完成。

---

## 验证是否成功

在 App Store 中搜索 **ChatGPT**，如果看到的是英文版且显示"GET"按钮，说明已成功切换到美区。

## 常见问题

**Q：注册时一定要挂梯子吗？**
A：不需要。注册页面填美国地区即可，不需要 VPN。但如果访问 Apple 官网有问题，可以开一下。

**Q：国内手机号可以用吗？**
A：目前已不可用，Apple 注册页面会拒绝非美国号码。需要用 TextNow 等工具获取美国虚拟号码。

**Q：付款方式选 None 之后还能买东西吗？**
A：可以，用礼品卡充值后余额扣款即可，不需要绑定信用卡。

**Q：这个 Apple ID 可以同时当主账号用吗？**
A：不建议。建议只用它登录 App Store，iCloud 和 iPhone 主账号保持不变，互不影响。
