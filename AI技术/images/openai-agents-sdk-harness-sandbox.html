Harness 与 Sandbox 的职责边界
控制面保管凭证与状态，计算面执行模型生成的操作，两者通过信任边界隔离

Harness · 控制面

可信基础设施 · 你的服务器

1
接收用户指令
解析任务描述，初始化 Agent 循环
2
调用模型
携带凭证发起 API 请求，获取模型响应
3
路由工具调用
将模型请求的工具操作路由到 Sandbox 执行
4
审批与追踪
记录所有操作日志，执行权限审批策略
5
状态持久化
外化运行状态，支持中断后恢复
TRUST BOUNDARY

Sandbox · 计算面

隔离环境 · 沙箱提供商

1
初始化工作空间
按 Manifest 描述准备文件、仓库、存储挂载
2
执行文件操作
基于 patch 的文件编辑，差量操作可审计可回滚
3
运行 Shell 命令
在隔离环境中执行命令、安装依赖、运行测试
4
记忆与技能
跨运行学习经验，动态发现和加载 Skills
5
快照与恢复
保存工作空间状态，支持在新容器中重建
控制面保管 API 密钥和凭证
模型生成的代码无法穿越信任边界
Sandbox 崩溃不影响运行状态
