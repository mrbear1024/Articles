# 读大学的目的

读大学的目的，不是为了找一份好工作，也不是为了将来赚很多很多的钱。

这两件事当然重要，但如果你把四年时间全部押注在求职和赚钱上，你会错过大学真正给你的东西。

# 交一群可能陪你走一辈子的朋友

18到22岁，是人一生中最容易交到真朋友的阶段。

原因很简单：这个年纪没有利益纠葛。你和室友分一包泡面，和同学通宵赶一份作业，和社团的人一起排练到凌晨——这些事情没有任何功利目的，纯粹因为你们恰好在同一个地方，经历着同一段时光。

工作以后你也会认识很多人，但关系的底色变了。同事之间有竞争，合作伙伴之间有利益，社交场合里每个人都带着身份和目的。你很难再找到一种关系，单纯到可以在深夜里聊三个小时毫无意义的话题，然后第二天一起去食堂吃早饭。

大学时期交到的朋友，很多会成为你未来人生中最信任的人。当你遇到困难，最先想到的往往不是某个商业伙伴，而是大学时代那个和你一起熬过期末考试的人。这种信任不是建立在交换之上，而是建立在共同经历之上。它的牢固程度，是成年后的社交关系很难达到的。

# 学会独立思考

大学之前，你的世界观基本上是父母和老师塑造的。他们告诉你什么是对的，什么是错的，什么值得追求，什么应该避免。你很少需要自己判断。

大学是你第一次被扔进一个没有标准答案的环境。你会遇到和你观点完全相反的同学，会读到颠覆你既有认知的书，会碰上让你困惑的问题——而没有人会直接告诉你答案。

这种困惑本身就是教育。

你开始学着自己分辨信息的真伪，学着在不同观点之间做出判断，学着接受世界的复杂性。这套思维能力一旦建立，会在此后几十年里持续发挥作用。遇到一条新闻，你会追问来源。面对一个决策，你会考虑多种可能。别人给你一个结论，你会习惯性地去审视它背后的逻辑。

这种能力不会写在简历上，但它决定了你面对未知时是焦虑还是从容。

# 搞清楚自己到底喜欢什么

18岁之前，你的时间被安排得明明白白：上课、做题、考试。你很少有机会停下来问自己一个问题——我到底喜欢什么？

大学给了你四年相对自由的时间去回答这个问题。你可以选修一门和专业毫无关系的课，可以加入一个从未接触过的社团，可以花整个暑假去做一件看起来"没用"的事。没有人会因为你的尝试失败而惩罚你。

这四年的试错成本极低。你还没有房贷，没有家庭负担，没有一份需要维护的职业声誉。如果你发现自己对当初选的专业毫无热情，你可以转方向。如果你突然对某个领域产生了强烈兴趣，你可以全力投入。

很多人在三四十岁时感到迷茫，本质上是因为他们从未认真回答过"我到底喜欢什么"这个问题。他们从高考志愿开始就在被推着走——选热门专业、找稳定工作、拿高薪offer——每一步都在回应外界的期待，唯独没有听过自己的声音。

大学是你最有条件去听这个声音的时候。别浪费它。

# 经历一段不被效率绑架的时光

这一点在今天尤其重要。

现代社会对效率的崇拜已经渗透到了生活的每个角落。每一分钟都要有产出，每一段经历都要能写进简历，每一个选择都要"有用"。在这种逻辑下，读一本和专业无关的书是浪费时间，参加一次没有学分的讨论是不务正业，花一个下午坐在草地上发呆是不可理喻。

但人的成长从来不是线性的。你日后最重要的想法，可能来自某次漫无目的的阅读。你最深的感悟，可能来自某个无所事事的下午突然想通的一件事。你对世界的理解，可能来自和一个完全不同背景的人的一次长谈。

大学是人生中少有的、被允许"低效"的阶段。你被免除了赚钱养家的压力，被免除了即刻产出成果的要求。你可以用四年时间慢慢地读书、思考、尝试、犯错、重来。

离开大学之后，这种奢侈几乎不会再有了。

# 回到那个问题

读大学的目的到底是什么？

是在功利还没有完全占据你的生活之前，用几年时间完成几件重要的事：交到真正的朋友，建立独立思考的能力，弄清楚自己是谁，以及学会在没有标准答案的世界里安放自己。

这些东西不会出现在任何一份成绩单上，但它们会塑造你整个人生的质量。

好工作会换，高薪会波动，但一个想明白了自己要什么的人，和一群值得信赖的朋友，是你这辈子最稳固的资产。
